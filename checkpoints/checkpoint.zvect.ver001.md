## §1 Concept

ZVect teaches vectors step by step, from "a vector is a list of numbers" to bi-encoder search and nearest-centroid
classification. Every lesson has: a 3D canvas you can orbit, the formula (MathML), the same formula with live numbers from
the canvas, and runnable code in JavaScript / C++ / Python shown as tabs. The vector library used by the lessons (`lib/`)
is also the deliverable: a single file per language that a person or another AI session can copy.

Owner rules (all เคาะ by the owner on 2026-10-10):
1. **No frameworks, no dependencies.** Exceptions only with a dated owner-approval row in `docs/APPROVALS.md` *before*
   the dependency is added. `npm test` fails if `package.json` lists any dependency.
2. **Dark theme only.** No light theme, no `prefers-color-scheme` switch (`web/css/style.css` header says so).
3. **Short and simple.** Every explanation and example is short; each lesson only uses ideas from earlier lessons.
4. **Grouped topics.** Owner asked for grouping; "Space" holds Vector space + Latent space.
5. Content language for learners: Thai, technical terms in English.
6. Non-commercial study license (`LICENSE`, bilingual, Thai prevails).

## §2 Architecture

- `lib/zvect.{js,py,hpp}` — same API and same edge-case rules in three languages. Rules: size mismatch / empty list /
  no centroids / empty table throw; cosine with a zero vector returns 0 by convention; ties keep input order (topK) or
  first label (classify); `fmt` prints 3 decimals with exact ties rounded to even so all three print identical text.
- `examples/{js,py,cpp}/NN_*.{js,py,cpp}` — one example per lesson; the web code tabs fetch these exact files.
  `npm run check` runs all three languages and requires byte-identical stdout.
- `tests/parity/{js,py,cpp}/edge_cases.*` — edge-case probes, also compared across languages by `npm run check`.
- `web/` — static app served by `server.js` (node:http, 127.0.0.1 by default). `web/js/scene3d.js` is a hand-written
  perspective renderer on Canvas 2D (orbit camera, painter's sort by layer then depth, near-plane line clipping).
  `web/js/kit.js` builds MathML and form controls. `web/lessons/NN_*.js` each export
  `{ slug, title, en, example, intro, try, formula, view?, axisNames?, mount(ui) -> { draw(s), live() } }`.
  `web/js/app.js` holds `GROUPS` (sidebar groups) and the hash router; the lessons import `/lib/zvect.js` directly.
- Distribution: `lib/MANIFEST.json` (version + sha256, regenerated by `npm run manifest`, checked by `npm test`),
  `llms.txt` (API + rules for other AI sessions), `lib/README.md` (Thai, three ways to use the lib),
  `package.json` `exports` so `npm install github:zardokar/ZVect` works.
