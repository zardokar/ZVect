บทสรุปย่อ

คลิป 1 นาทีครึ่งนี้เป็นเดโม Transformer Explainer ที่เผยแพร่ปี 2024 (ผู้จัดทำเข้าใจว่าเป็นรุ่นก่อนเดโมปี 2025) เครื่องมือแบบ interactive ที่ตามคำอธิบายคลิป (ข้อความเดียวกับบทคัดย่อของ paper arXiv 2408.04619 ไม่ใช่เนื้อหาที่พูดหรือเห็นในคลิป) รัน GPT-2 สดในเบราว์เซอร์ให้ผู้ใช้ทดลองกับข้อความของตัวเอง และเห็นว่าส่วนประกอบภายใน Transformer ทำงานร่วมกันอย่างไรเพื่อทำนาย token ถัดไป คลิปไม่มีคำพูด (ไฟล์ caption มีแต่ [music]) เนื้อหามาจาก caption บนจอและหัวข้อบทในคำอธิบายคลิป ลำดับคือ ปรับ Temperature, ดู GPT-2 อัปเดตค่าทั้งหมดสด, เลือกหรือพิมพ์ prompt เอง, ดู Self-Attention matrix, ดูการแปลงข้อความเป็น token กับ embedding และตามคณิตศาสตร์เบื้องหลังทีละขั้น

โหมดเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ ครบทุกประเด็น (license มาตรฐานของ YouTube) คลิปไม่มีบทพูด (caption ASR มีแต่ [music]) เนื้อหามาจากข้อความ caption บนจอ ภาพหน้าจอ และหัวข้อบทในคำอธิบายคลิป

1. ภาพรวมของเครื่องมือ (~0:00–0:08)

คลิปเปิดด้วยหน้าต่างเบราว์เซอร์ที่เปิดเว็บ Transformer Explainer และ caption ที่บอกว่า Transformer Explainer แสดงให้เห็นว่าโมเดล สร้างข้อความ (text-generative) ทำงานอย่างไร (~0:03) หน้าจอเป็นแผนภาพเดียวที่ไหลจากซ้ายไปขวา มีป้ายคอลัมน์ Embedding, Multi-head Self Attention, MLP และ Probabilities ส่วนบนมีช่องข้อความ ปุ่ม Generate และแถบ Temperature ข้อความที่ป้อนขณะนั้นคือ Data visualization empowers users to และท้ายข้อความมีจุดสามจุดที่แสดงว่ากำลังรอ token ถัดไป ตามคำอธิบายคลิป (ข้อความเดียวกับบทคัดย่อของ paper arXiv 2408.04619 ไม่ใช่เนื้อหาที่พูดหรือเห็นในคลิป) เครื่องมือรัน GPT-2 สดในเบราว์เซอร์ ให้ผู้ใช้ทดลองกับข้อความของตัวเอง และดูส่วนประกอบและการคำนวณภายในของ Transformer ทำงานร่วมกันเพื่อทำนาย token ถัดไป

2. ปรับ Temperature (~0:08–0:20)

caption (~0:10) บอกให้ปรับ แถบเลื่อน Temperature เพื่อควบคุมความน่าจะเป็นของคำที่ทำนาย ภาพซูมเข้าไปที่แถบเลื่อน ซึ่งขณะนั้นอ่านได้ 0.6 และรายการ Probabilities ทางขวาแสดง visualize 29.48% เป็นอันดับหนึ่ง ตามด้วย create 12.17%, see 7.41%, make 4.09%, easily 4.01%, quickly 3.76%, explore 3.52%, find 2.62%, understand 2.00% และคำถัดลงไปเป็น <0.01% แต่ละคำมีแถบสีม่วงสั้นยาวตามความน่าจะเป็น คำอันดับหนึ่งเป็นตัวหนาสีม่วง คำที่เหลือเป็นสีเทา ข้อความ "11 more identical Transformer Blocks" ที่ชี้ลูกศรลงมาจากด้านบนบอกว่าบล็อกที่เห็นเป็นเพียงหนึ่งในสิบสองบล็อกที่เหมือนกัน

3. GPT-2 อัปเดตค่าสด เลือก prompt และพิมพ์เอง (~0:20–0:44)

สามหัวข้อของช่วงนี้มาจากรายการบทในคำอธิบายคลิป ได้แก่ ที่ 0:20 GPT-2 สดอัปเดตค่าทั้งหมด, ที่ 0:27 เลือก prompt และที่ 0:35 พิมพ์ prompt เอง ส่วนที่เห็นบนจอ ที่ ~0:18 ข้อความต่อท้ายด้วยคำ quickly และคำนี้ถูกไฮไลต์ในรายการ Probabilities (2.59%) ที่ ~0:26 ข้อความกลายเป็น Data visualization empowers users to quickly find โดยเมาส์อยู่ใกล้ปุ่ม Generate ที่ ~0:33 ผู้ใช้เลือกประโยค As the spaceship was approaching the Earth จากเมนู Examples ทำให้จำนวน token ในแผนภาพเปลี่ยนเป็น 8 และรายการ Probabilities เปลี่ยนตาม ที่ ~0:40 ข้อความต่อท้ายด้วยคำ we และช่องอินพุตขึ้นจุดสามจุดระหว่างรอผลการทำนาย (เฟรมไม่ได้บอกว่าคำ we มาจากการพิมพ์หรือจากการ Generate)

ข้อจำกัดของหลักฐานในส่วนนี้

caption ของช่วง 0:20–0:40 ไม่ได้ติดอยู่ในเฟรมที่จับมา จึงยึดหัวข้อจากคำอธิบายคลิปและบรรยายเฉพาะสิ่งที่เห็นในเฟรมเท่านั้น

4. Self-Attention matrix (~0:44–0:56)

caption (~0:47) ชวนให้ลองดูว่า คำโต้ตอบกันอย่างไรใน Self-Attention matrix ภาพซูมเข้าไปที่ส่วนนี้ เส้นสายของ Query (สีฟ้า) และ Key (สีแดง) ลากจากชื่อ token (As, the, spaceship, was, approaching, the, Earth, we) ไปรวมกันเป็นตาราง 8 × 8 ของจุดสีม่วง จุดเข้มคือค่ามาก ใต้ตารางมีป้าย "Dot product" และแถบสี −29.9 ถึง 5.4 ผล Value (สีเขียว) ไหลไปรวมเป็น Out และมุมล่างของการ์ดมีป้าย "Head 1 of 12" ในภาพ ที่ ~0:54 รายการ Probabilities ของประโยค spaceship เรียง were 17.34%, could 16.64%, saw 12.28%, had 11.24% ตามลำดับ และคำ thought ถูกไฮไลต์ที่ <0.01%

5. จากข้อความเป็น Token และ Embedding (~0:56–1:03)

caption (~1:00) บอกให้ดูว่า ข้อความถูกแปลงเป็น Token และ Embedding อย่างไร เมื่อคลิกที่ป้าย Embedding หน้าจอขยายเป็นตารางหนึ่งแถวต่อ token: ชื่อ token, ลูกศร, แถบสี Token Embedding พร้อม id (As 5864, the 1276, spaceship 460, was 2369, approaching 2961, the 617, Earth 2186, we 5331), เครื่องหมาย +, แถบสี Positional Encoding พร้อมเลข position (0, 1, 2, …) แล้วเครื่องหมาย = ตามด้วยแถบสีผลรวม หัวคอลัมน์ Token Embedding และ Positional Encoding มีไอคอนเครื่องหมายคำถามให้อ่านคำอธิบายเพิ่ม

เสริมจากผู้จัดทำ

id ของคำ the ในประโยคเดียวกันบนจอเป็น 1276 และ 617 ต่างกัน ตัวเลขนี้จดตามที่เห็นบนเฟรม คลิปไม่ได้อธิบาย (ผู้จัดทำ)

6. คณิตศาสตร์เบื้องหลังทีละขั้น และท้ายคลิป (~1:03–1:28)

caption (~1:06) ให้ ตามการดำเนินการทางคณิตศาสตร์ทีละขั้น ป๊อปอัปชื่อ Weight Multiplication วางสมการเป็นเมทริกซ์ ได้แก่ Token Embedding ขนาด (8, 768) คูณ Q·K·V Weights ขนาด (768, 2304) บวก bias เวกเตอร์ (2304) เท่ากับ Q·K·V ขนาด (8, 2304) ตัวเมทริกซ์น้ำหนักแบ่งเป็นสามแถบสีฟ้า แดง เขียว (Q, K, V) สูตรด้านล่างเขียนผลคูณของช่องแรก (E₁,₁·W₁,₁ + E₁,₂·W₂,₁ + … + E₁,₇₆₈·W₇₆₈,₁) + b₁ = QKV₁,₁

ที่ ~1:12 ผลลัพธ์ฝั่งขวาถูกเติมเป็นแถบสีฟ้า แดง เขียวต่อ token (แถวที่ยังคำนวณไม่ถึงเป็นช่องว่าง) และสูตรด้านล่างเปลี่ยนเป็นแบบรวม Σ (d=1 ถึง 768) E_id · W_dj + b_j = QKV_ij ที่ ~1:18 และ ~1:24 คลิปจบด้วยการ์ดชื่อ Transformer Explainer พร้อมคำบรรยาย "Interactive Learning of Text-Generative Models" ภาพย่อของเครื่องมือ และลิงก์ให้ลองใช้ poloclub.github.io/transformer-explainer

สมการใน Weight Multiplication (แสดงบนจอ: สูตรใต้ป๊อปอัปและเมทริกซ์สามก้อน)

(E1,1⋅W1,1+E1,2⋅W2,1+⋯+E1,768⋅W768,1)+b1=QKV1,1(2)
∑d=1768EidWdj+bj=QKVij(3)
QKV=EW+b(4)
QKV=[Q|K|V](5)
สัญลักษณ์ความหมายขนาดที่มา
EToken Embedding ของทั้งประโยค (E_id = แถว i คอลัมน์ d)(8, 768)แสดงบนจอ
WQ·K·V Weights (W_dj = แถว d คอลัมน์ j)(768, 2304)แสดงบนจอ
bbias (b_j = ค่าที่ j)(2304)แสดงบนจอ
QKVผลลัพธ์ Q·K·V (QKV_ij = แถว i คอลัมน์ j)(8, 2304)แสดงบนจอ
i, j, di = token (1–8), j = คอลัมน์ผลลัพธ์ (1–2304), d = 1…768 ที่ถูกรวมแสดงบนจอ (สมการ 3)
Q, K, Vสามส่วนของผลลัพธ์ที่แสดงเป็นแถบสีฟ้า แดง เขียวส่วนละ 768 คอลัมน์ผู้จัดทำ (บนจอเห็นเพียงสามแถบสี ตัวเลข 768 เป็นข้อสรุปจาก 2304 ÷ 3)

สมการ (2) และ (3) คือสูตรที่ป๊อปอัปเขียน สมการ (4) เป็นการเขียนการคูณเมทริกซ์ในรูปย่อที่ผู้จัดทำสรุปจากเครื่องหมาย × + = ระหว่างเมทริกซ์ และสมการ (5) เป็นข้อสรุปของผู้จัดทำจากการแบ่งสีสามส่วน

Key Takeaways

1.เครื่องมือรัน GPT-2 สดในเบราว์เซอร์ ให้ทดลองกับ prompt เองได้ (ตามคำอธิบายคลิป ซึ่งตรงกับบทคัดย่อของ paper ไม่ใช่เนื้อหาที่เห็นในคลิป)
2.Temperature เปลี่ยนความน่าจะเป็นของคำที่ทำนาย และรายการ Probabilities ตอบสนองทันที
3.Self-Attention matrix แสดงเป็นตารางจุดสีม่วง 8 × 8 สำหรับประโยค 8 token และดูได้ทีละ head (Head 1 of 12)
4.Embedding ขยายดูได้ว่า token id บวก positional encoding แล้วเป็นเวกเตอร์ตั้งต้น
5.ป๊อปอัป Weight Multiplication แสดงทั้งขนาดเมทริกซ์และสูตรของแต่ละช่อง
