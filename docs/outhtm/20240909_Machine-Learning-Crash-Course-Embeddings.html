📋 บทสรุปย่อ

บทสรุปย่อ: คลิปสั้น 2 นาทีครึ่งของ Google ตอบคำถามว่า embedding ของคำ "มาจากไหน" โดยเดินผ่านโครงข่าย word2vec หนึ่งแบบ: ชั้นนำเข้าที่ใช้ one-hot ได้ (หนึ่งช่องต่อหนึ่งคำ) → ชั้น embedding / projection (จำนวนโหนด = จำนวนมิติที่ต้องการ ไม่มี activation) → (ใช้ได้) ชั้นซ่อน → ชั้นผลลัพธ์ที่มีหนึ่งโหนดต่อคำพร้อม softmax ฝึกด้วยคู่ (คำ, คำข้างเคียงในประโยคเดียวกัน) ที่เรียกว่า skip-gram หลังฝึก น้ำหนักระหว่างชั้นแรกกับชั้นที่สองคือ embedding matrix และคำที่คล้ายกันมักจะอยู่ใกล้กัน เช่น embedding ของ sail กับ ship น่าจะอยู่ใกล้กัน

โหมดของเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ (license มาตรฐานของ YouTube, ตรวจ 2026-10-11) ครบทุกประเด็นตามลำดับคลิป ไม่เปลี่ยนความหมาย ไม่ได้ถอดคำพูดทีละประโยค

🧭 สรุปเชิงลึก

คำถามของคลิป: เรารู้แล้วว่าโครงข่ายประสาทแทนคำด้วย embedding แต่ embedding มาจากไหน คลิปตอบว่ามีสถาปัตยกรรมเฉพาะสำหรับงานนี้ และยกตัวอย่าง word2vec หนึ่งแบบ พร้อมย้ำว่า "ทำได้หลายวิธี นี่เป็นเพียงตัวอย่างหนึ่ง"

โครงสร้าง 4 ชั้น: (1) ชั้นนำเข้าใช้ one-hot ได้ จึงต้องมีหนึ่งโหนดต่อหนึ่งคำในคลังคำ (2) ต่อแบบเต็มทุกเส้นไปยังชั้นที่มีหนึ่งโหนดต่อหนึ่งมิติของ embedding เช่น อยากได้ 10 มิติก็ใช้ 10 โหนด ชั้นนี้มักเรียกว่า projection layer หรือ embedding layer และไม่ต้องมี activation (3) หลังชั้น embedding ใช้ชั้นซ่อนแบบเต็มที่มี activation บางชนิดเพื่อประมวลผลต่อได้ (4) ชั้นผลลัพธ์หน้าตาเหมือนชั้นนำเข้า คือหนึ่งโหนดต่อหนึ่งคำ แล้วใช้ softmax เพื่อ normalize ผลลัพธ์ (ความรู้ทั่วไป: ทำให้ค่าทุกโหนดรวมกันได้ 1)

ข้อมูลฝึก: ให้คำหนึ่งคำแล้วทายว่าคำไหนอยู่ในบริบทเดียวกัน แปลงข้อความก้อนใหญ่ (คลิปยกตัวอย่างนิยายภาษาอังกฤษทุกเล่มใน Project Gutenberg หรือบทความทั้งหมดของ Wikipedia ภาษาอังกฤษ) เป็นคู่ input–output: input = คำในข้อความ, output = คำใกล้ ๆ ในประโยคเดียวกัน คู่แบบนี้เรียกว่า skip-gram ยิ่งสร้างคู่มาก โมเดลยิ่งดี แต่ฝึกนานขึ้น

ผล: น้ำหนักระหว่างชั้นที่ 1 กับชั้นที่ 2 คือ embedding matrix การหา embedding ของคำหนึ่ง คือหยิบน้ำหนักทั้งหมดของคำนั้นมาเรียงเป็นเวกเตอร์ เวกเตอร์ที่ได้มีมิติน้อยกว่า one-hot และเก็บข้อมูลเรื่องความหมาย คำที่คล้ายกันมัก (tend to) อยู่ใกล้กัน เช่น "sail" กับ "ship" น่าจะใกล้กัน ส่วน "how" น่าจะไกล

ข้อจำกัดที่คลิปบอกเอง: โครงข่ายนี้ไม่ได้ออกแบบมาเพื่อประสิทธิภาพ ใช้เวลาและหน่วยความจำมากในการฝึก ส่วนวิธีปรับสถาปัตยกรรมให้มีประสิทธิภาพให้ไปอ่านแหล่งในคำอธิบาย

ข้อควรรู้ (เสริมจากผู้จัดทำ): word2vec ต้นฉบับ (skip-gram) ไม่มีชั้นซ่อนที่มี activation คั่นกลาง ชั้นซ่อนในคลิปเป็นตัวเลือกที่คลิปพูดว่า "ใช้ได้" (can use) จึงไม่ขัดกัน แต่ถ้าจะเทียบกับเปเปอร์ต้นฉบับให้รู้ว่าต่างกันตรงนี้
โยงกับ ZVect: การหยิบแถวของคำตรงกับบท 3.6 Embedding matrix (one-hot × matrix = แถว)

1. embedding มาจากไหน (~0:00–0:21)

คลิปเริ่มจากสิ่งที่ผู้ชมรู้แล้ว: โครงข่ายประสาทแทนคำด้วย embedding คำถามคือเวกเตอร์เหล่านี้มาจากไหน คำตอบคือมีสถาปัตยกรรมโครงข่ายที่ทำมาเพื่องานนี้โดยเฉพาะ คลิปเลือกเดินผ่านโครงข่าย word2vec ที่เรียนวิธีแทนคำเป็นเวกเตอร์หลายมิติ และเน้นว่ามีหลายวิธี นี่เป็นเพียงตัวอย่างหนึ่ง

ข้อสังเกตของผู้จัดทำ: โครงสร้างในคลิปจึงไม่ใช่สูตรเดียวที่ถูก แต่ช่วยให้เห็นว่า "ตารางเวกเตอร์ของคำ" เกิดจากการฝึกโครงข่ายให้ทายบางอย่าง ไม่ใช่ตัวเลขที่คนกรอกเอง
โยงกับ ZVect: บท 3.7 "ตารางมาจากการฝึก" ใช้แนวคิดเดียวกัน (เริ่มสุ่ม แล้วปรับจากคำข้างเคียง)

2. สี่ชั้นของโครงข่าย (~0:23–1:11)

ชั้นที่ 1 — นำเข้า: ใช้ one-hot ได้ จึงต้องมีโหนดนำเข้าหนึ่งโหนดต่อหนึ่งคำในคลังคำ คำที่เลือกเป็น 1 ช่องอื่นเป็น 0

ชั้นที่ 2 — embedding: ต่อแบบ fully connected ไปยังชั้นที่มีหนึ่งโหนดต่อหนึ่งมิติของ embedding ที่ต้องการ ถ้าต้องการ 10 มิติ ชั้นนี้มี 10 โหนด ชื่อที่ใช้กันคือ projection layer หรือ embedding layer และเป็นที่ที่ embedding ถูกเรียนรู้ คลิปบอกชัดว่าชั้นนี้ไม่ต้องมี activation function

ชั้นที่ 3 — ซ่อน: หลังชั้น embedding "ใช้" ชั้นซ่อนแบบเต็มที่มี activation บางชนิดเพื่อประมวลผลต่อได้

ชั้นที่ 4 — ผลลัพธ์: หน้าตาเหมือนชั้นนำเข้า คือหนึ่งโหนดต่อหนึ่งคำ และใช้ softmax เพื่อ normalize ผลลัพธ์ (ความรู้ทั่วไป: softmax ทำให้ค่าทุกโหนดเป็นความน่าจะเป็นที่รวมกันได้ 1)

3. ฝึกด้วย skip-gram (~1:12–1:49)

เมื่อมีโครงข่ายแล้ว ฝึกอย่างไร: ให้คำหนึ่งคำ แล้วให้ทายว่าคำไหนปรากฏในบริบทเดียวกัน ขั้นแรกเอาข้อความก้อนใหญ่มาแปลงเป็นคู่ input–output คลิปยกตัวอย่างนิยายภาษาอังกฤษทุกเล่มใน Project Gutenberg หรือบทความทั้งหมดของ Wikipedia ภาษาอังกฤษ input คือคำหนึ่งคำในข้อความ output (ค่าที่ต้องทาย) คือคำใกล้ ๆ ที่อยู่ในประโยคเดียวกัน คู่แบบนี้มีชื่อว่า skip-gram

ปริมาณคู่เป็นข้อแลก: ยิ่งสร้าง skip-gram มาก โมเดลยิ่งดี แต่ใช้เวลาฝึกนานขึ้น

ตัวอย่างรูปธรรม (ผู้จัดทำ): ประโยค "the ship can sail far" ถ้าเลือกคำข้างเคียงในระยะ 1 คำ จะได้คู่ (ship, the), (ship, can), (can, ship), (can, sail), (sail, can), (sail, far) … โครงข่ายถูกปรับให้เมื่อเห็น ship แล้วให้ความน่าจะเป็นสูงกับ the และ can — คลิปไม่ได้กำหนดขนาดหน้าต่าง (window) ตัวเลข 1 คำเป็นค่าที่ผู้จัดทำเลือกเพื่ออธิบาย

4. หลังฝึก: embedding matrix และความใกล้ของความหมาย (~1:50–2:21)

หลังฝึก น้ำหนักระหว่างชั้นที่ 1 กับชั้นที่ 2 คือ embedding matrix อยากได้ embedding ของคำไหน ก็หยิบน้ำหนักทั้งหมดที่ออกจากคำนั้นมาเรียงเป็นเวกเตอร์ (ในภาพ โหนดของคำที่มีค่า 1 มีสามเส้นไปยังสามโหนด น้ำหนัก w_0, w_1, w_2 จึงเรียงเป็นเวกเตอร์ 3 มิติหนึ่งตัว)

เวกเตอร์ที่ได้มีมิติน้อยกว่า one-hot และเก็บข้อมูลเกี่ยวกับความหมายของคำ ผลหนึ่งคือคำที่คล้ายกันมักจะอยู่ใกล้กันในปริภูมิเวกเตอร์ คลิปยกตัวอย่างว่า embedding ของ "sail" กับ "ship" น่าจะอยู่ใกล้กัน ส่วน "how" น่าจะอยู่ไกล

โยงกับ ZVect: "หยิบน้ำหนักของคำมาเรียง" = one-hot × matrix ได้แถวเดียวกับการเปิดตารางด้วยเลข ID (บท 3.4 One-hot, 3.6 Embedding matrix)

5. ข้อจำกัดและสิ่งที่ควรเข้าใจให้ตรง (~2:22–2:35)

คลิปปิดท้ายว่าโครงข่ายง่าย ๆ นี้ไม่ได้ออกแบบมาเพื่อประสิทธิภาพ ใช้เวลาและหน่วยความจำมากในการฝึก ถ้าอยากรู้วิธีปรับสถาปัตยกรรม embedding ให้มีประสิทธิภาพให้ดูแหล่งในคำอธิบายคลิป (คำอธิบายลิงก์ไปบทเรียน Embeddings ของ Machine Learning Crash Course)

ข้อที่ควรเข้าใจให้ตรง (เสริมจากผู้จัดทำ):
  • word2vec แบบ skip-gram ในเปเปอร์ต้นฉบับไม่มีชั้นซ่อนที่มี activation คั่นระหว่าง embedding กับ softmax คลิปพูดว่า "ใช้ได้" จึงเป็นตัวเลือกของตัวอย่างนี้ ไม่ใช่ข้อกำหนดของ word2vec
  • ผลลัพธ์ softmax หนึ่งโหนดต่อหนึ่งคำคือสาเหตุที่ช้า (ต้องคำนวณทุกคำในคลังทุกครั้ง) วิธีเร่งที่ใช้กันเช่น negative sampling — คลิปไม่ได้พูดถึงชื่อวิธี (ความรู้ทั่วไป)
  • "คำคล้ายกันอยู่ใกล้กัน" เป็นแนวโน้มที่คลิปพูดด้วยคำว่า tend to / likely ไม่ใช่การรับประกัน

Key Takeaways

  1. embedding ของคำเกิดจากการฝึกโครงข่ายให้ทายคำในบริบทเดียวกัน (ผู้จัดทำ: จึงไม่ใช่ตัวเลขที่คนกรอกเอง)
  2. ชั้น embedding มีหนึ่งโหนดต่อหนึ่งมิติ และไม่มี activation
  3. หลังฝึก น้ำหนักชั้น 1 → 2 คือ embedding matrix: หยิบน้ำหนักของคำ = เวกเตอร์ของคำ
  4. skip-gram = คู่ (คำ, คำใกล้ ๆ ในประโยคเดียวกัน) ยิ่งมากยิ่งดีแต่ฝึกนาน
  5. คำที่คล้ายกันมักอยู่ใกล้กัน (sail–ship) · โครงข่ายนี้ไม่ได้ออกแบบเพื่อประสิทธิภาพ ใช้เวลาและหน่วยความจำมาก
