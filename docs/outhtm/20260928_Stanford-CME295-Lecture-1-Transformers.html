บทสรุปย่อ

คาบแรกของวิชา CME295 (Transformers & Large Language Models) ที่ Stanford สอนโดยพี่น้องฝาแฝด Afshine และ Shervine Amidi เล่าว่าเรามาถึง LLM ได้อย่างไร: จากยุค model เฉพาะงานที่ใช้ RNN ไปถึงบทความ "Attention Is All You Need" (2017) แล้วไล่พื้นฐานทีละชั้น คือ tokenization, word2vec, RNN / LSTM, attention, self-attention ด้วย query / key / value และสูตร softmax(QKᵀ/√d_k)V ครึ่งหลังอธิบายสถาปัตยกรรม transformer แบบ encoder–decoder สำหรับแปลภาษา ทั้ง position embedding, multi-head attention, feed forward, residual, layer norm, masked self-attention, cross-attention แล้วปิดด้วยตัวอย่างแปล "A cute teddy bear is reading." ทีละขั้นพร้อมขนาดของเมทริกซ์ทุกตัว

โหมดเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ ครบทุกประเด็นและตัวเลข พร้อมตรวจข้อเท็จจริงกับบทความต้นฉบับ (license มาตรฐานของ YouTube · ใช้คำบรรยายภาษาอังกฤษที่ทำด้วยคน)

สรุปเชิงลึก

ภาพใหญ่: ยุค 2010s มี model หนึ่งตัวต่องาน (วิเคราะห์ความรู้สึก, แปลภาษา, หาชื่อคน) ส่วนใหญ่เป็น RNN จุดเปลี่ยนคือปี 2017 กับบทความ "Attention Is All You Need" ที่เสนอ transformer ซึ่งผู้สอนบอกว่า scale ได้ดีมาก ให้ข้อมูล การคำนวณ และพารามิเตอร์มากขึ้นแล้วผลดีขึ้นกว่าแบบเดิมมาก จากนั้นคนขยาย model และจำนวน token ที่ฝึกจนเป็น LLM ปัจจุบัน ChatGPT (พ.ย. 2022) เป็นจุดเปลี่ยนด้านผลิตภัณฑ์ และปี 2026 ผู้สอนเดาว่านักศึกษาหลายคนหรือทุกคนใช้ coding agent แทบทุกวัน ฐานราก: model เข้าใจตัวเลข ไม่เข้าใจข้อความ จึงต้องตัดข้อความเป็น token ด้วยคลังคำ (vocabulary) แบบคำ ตัวอักษร หรือคำย่อย (subword) มีข้อดีข้อเสียต่างกัน และ subword แบบ BPE นิยมที่สุด คลังคำของ LLM ปัจจุบันมีหลักแสน token (เช่น 200,000) แล้วแทน token ด้วยเวกเตอร์ one-hot ซึ่งทุกคู่ตั้งฉากกันจึงไม่บอกความหมาย word2vec จึงฝึก network เล็กกับงานแทน (proxy task) แล้วเก็บ hidden representation ขนาด D เป็น embedding แต่ word2vec ไม่สนบริบท (bank) และไม่สนลำดับคำ จาก RNN ถึง self-attention: RNN เก็บ hidden state ที่สรุปประโยคที่อ่านมา จึงรู้ลำดับคำ แต่จำของไกลได้ยาก (long-range dependency จาก vanishing gradient) LSTM เพิ่ม cell state เพื่อพาข้อมูลไปได้ไกลขึ้น แต่ผู้สอนบอกว่ายังมีปัญหาเดิม และทั้งคู่ต้องอ่านทีละ token ทำให้ฝึกช้ามาก attention (สไลด์ระบุปี 2014) ให้ model ต่อตรงไปยัง token ก่อนหน้า ส่วน self-attention ให้ทุก token แสดงเป็นฟังก์ชันของทุก token ในลำดับ ผ่าน query, key, value ที่ได้จากเมทริกซ์ฉาย W_Q, W_K, W_V แล้วรวมเป็น softmax(QKᵀ/√d_k)V ซึ่งผู้สอนบอกว่าน่าจะเป็นสูตรที่สำคัญที่สุดของ transformer สถาปัตยกรรม: token embedding บวก position embedding (แบบ sin/cos ความถี่ต่างกัน เปรียบกับเข็มนาฬิกา) → encoder (self-attention + feed forward) ซ้อน N = 6 ชั้น → decoder เริ่มจาก [BOS] มี masked self-attention, cross-attention (query จาก decoder, key / value จาก encoder) และ feed forward → linear + softmax ได้ความน่าจะเป็นของ token ถัดไป → เติมกลับแล้ววนจนได้ [EOS] เทคนิคเสริมคือ residual, layer norm, mask, multi-head (h หัวแล้วฉายด้วย W_O), dropout และ label smoothing ผู้สอนสรุปว่าแก่นคือ attention กับ feed forward ที่เก็บพารามิเตอร์ส่วนใหญ่ ผลตรวจ (ผู้จัดทำ): ตรวจ 16 ข้อ ยืนยัน 12 · บางส่วน 4 · ไม่พบข้อผิด ค่า N = 6 ตรงกับที่ผู้สอนบอก ส่วน h = 8, d_model = 512, d_ff = 2048, label smoothing 0.1 และผลที่ position แบบเรียนรู้กับ sin/cos ได้ใกล้กัน ผู้สอนไม่ได้กล่าวถึง (มาจากบทความ) ข้อที่ยืนยันไม่ได้คือเรื่อง tweet ของ ChatGPT ที่พิมพ์ผิด และ "พารามิเตอร์ส่วนใหญ่อยู่ใน feed forward" ถูกในระดับ block ของ encoder แต่ทั้ง model base ส่วน feed forward ราว 39% เอาไปใช้: เป็นคาบทฤษฎีที่เรียงเหตุผลได้ดีที่สุดในแหล่งที่อ่านมา ว่าแต่ละขั้นแก้ปัญหาอะไรของขั้นก่อน เหมาะเป็นโครงของบท Transformer (ผู้จัดทำ)

Afshine Amidi สอนวิชานี้กับ Shervine ฝาแฝดของเขา ทั้งคู่เรียนที่ Centrale Paris ในฝรั่งเศส แล้วมาเรียนต่อในสหรัฐ (Afshine ที่ MIT, Shervine ที่ ICME ของ Stanford) จากนั้นทำงานที่ Uber แล้ว Google และตอนนี้อยู่ Netflix ทั้งคู่ทำงานด้าน LLM มาตั้งแต่ราวต้นทศวรรษ 2020 สอนเนื้อหานี้หลายรูปแบบมาตั้งแต่ 2021 และเป็นวิชาจริงของ Stanford ตั้งแต่ปีที่แล้ว ครั้งนี้เป็นครั้งที่สาม เป้าหมาย: ให้รู้ว่า LLM ทำงานอย่างไร โดยเฉพาะกลไกของสถาปัตยกรรม (transformer) วิธีฝึก วิธีใช้ ทำอะไรได้ดีและไม่ดี กลุ่มผู้เรียน: ผู้สอนมองว่าค่อนข้างกว้าง ได้แก่ คนที่อยากเป็นนักวิจัย (เปิดมุมมองเทคนิคและการใช้งาน) คนที่ทำโปรเจกต์ส่วนตัว (ผู้สอนบอกว่าน่าจะควรรู้ว่า coding agent ทำอะไรได้ดีหรือไม่ดี) และทุกคนไม่ว่าทำงานอะไร เพราะความรู้เรื่อง AI (AI literacy) สำคัญขึ้นเรื่อย ๆ ถ้าอยู่ในกลุ่มใดกลุ่มหนึ่ง วิชานี้อาจเหมาะ พื้นฐานที่ควรมี: พีชคณิตเชิงเส้น (เมทริกซ์ การคูณ) และ ML เบื้องต้น เช่น loss function, neural network, embedding แม้วิชาจะสอนเรื่องเหล่านี้ด้วย

2. ต่างจากปีที่แล้ว และการจัดการวิชา (~3:43–12:42)

คาบเรียนถูกบันทึกเหมือนปีที่แล้ว แต่วงการเปลี่ยนเร็วมาก วิชาจึงใส่ความก้าวหน้าใหม่ ๆ เช่น ด้าน post-training อย่าง on-policy distillation, AI agent อย่าง coding agent และกระบวนทัศน์ใหม่ของ LLM: เดิมทาย token ทีละตัว แต่มี model มากขึ้นที่ทำต่างไป เช่น แนว diffusion ผู้สอนจึงขอให้คนที่เตรียมสอบดูคลิปของปีนี้ เพราะต่างกันมาก

  • เรียนทุกวันศุกร์ 3:30–5:20 เป็นวิชา 2 หน่วยกิต เลือกแบบเกรดหรือผ่าน/ไม่ผ่านได้ คลิปขึ้นเว็บวิชา (ซึ่งมีแผนการสอนด้วย) ภายในสองวันหลังเรียน ดูออนไลน์หรือมาเรียนก็ได้ แต่ผู้สอนอยากเห็นตัวจริงในห้อง
  • ไม่มีการบ้าน มีสอบสองครั้ง กลางภาค (เนื้อหาสี่คาบแรก, 23 ตุลาคม) และปลายภาค (ห้าคาบสุดท้าย) รวม 9 คาบ ผู้สอนบอกว่าสอบแต่ละครั้งคิดเป็น 50% · ข้อสอบปีก่อน (แท็บ 2025) อยู่บนเว็บ เป็นปรนัยและข้อเขียน
  • ไม่มีชั่วโมงให้คำปรึกษาทางการ แต่ผู้สอนทั้งสองจะอยู่ให้ถามหลังเลิกเรียนทุกครั้ง และมีระบบ Ed ให้ถาม · ประกาศผ่าน Canvas · คำถามส่วนตัวส่งทาง mailing list หรืออีเมล
  • สไลด์ขึ้นเว็บหนึ่งวันก่อนเรียน เพราะนักศึกษาอยากจดลงสไลด์ · ตำรา Super Study Guide: Transformers and LLMs (ผู้สอนเชื่อว่าห้องสมุดมีให้ยืมสองสามเล่ม และหาได้ทางออนไลน์) · cheat sheet ตั้งใจให้ทันสมัยที่สุดและสรุปทั้งวิชาแบบกระชับ เพิ่งอัปเดตเมื่อไม่กี่สัปดาห์ก่อน อาจเหมาะใช้ทบทวนก่อนสอบแต่ละครั้ง มีราว 15 ภาษา (รวมอังกฤษ) ใครอยากแปลภาษาของตัวเองติดต่อได้

ถามตอบ: วิชาโยงกับงานจริงในอุตสาหกรรม โดยเฉพาะครึ่งหลัง (ปีที่แล้วมีของใหม่ออกระหว่างสอน จึงปรับเนื้อหาไปด้วย) · ผู้สอนคิดว่าเรียนสม่ำเสมอได้ผลดีที่สุด และที่สำคัญที่สุดคือตั้งใจฟังสิ่งที่สอนในห้อง เนื้อหาในตำราที่ไม่ได้สอน ผู้สอนบอกว่าไม่น่าจะออกสอบ และโดยคร่าว ๆ สิ่งที่พูดในห้องออกสอบได้ทั้งหมด · มีข้อสอบปี 2025 ให้ฝึก แต่ข้อสอบจะต่างกัน มีเวลาเรียนต่อสัปดาห์จำกัด (ผู้สอนพูดว่า "สองชั่วโมง หรือหนึ่งชั่วโมง 15 นาที") จึงสอนไม่ครบทุกเรื่อง สไลด์ส่วนใหญ่จึงมีแหล่งอ้างอิงด้านล่างให้อ่านเพิ่ม ผู้สอนบอกว่าวงการนี้มีตัวย่อเยอะจนน่ากลัว และหวังว่าจบวิชาแล้วจะจับคู่ตัวย่อกับแนวคิดได้

3. เรามาถึง LLM ได้อย่างไร (~12:42–16:56)

10–15 ปีก่อน (ยุค 2010s) ไม่มี model เดียวที่ทำทุกอย่าง แต่มี model หนึ่งตัวต่องาน ส่วนใหญ่เป็น RNN (recurrent neural network) เช่น model วิเคราะห์ว่ารีวิวเป็นบวก ลบ หรือกลาง model แปลภาษา model หาชื่อคนและสถานที่ ผลก็พอใช้ได้ จุดเปลี่ยนคือ 2017 บทความ "Attention Is All You Need" เสนอสถาปัตยกรรมใหม่ที่ผู้สอนบอกว่า scale ได้ดีมาก คือให้ข้อมูล การคำนวณ และพารามิเตอร์มากขึ้น แล้วผลดีขึ้นมากกว่าที่เคยเห็น สถาปัตยกรรมนี้ชื่อ transformer แล้วคนก็ขยายทั้งขนาด model และจำนวน token ที่ฝึก จนได้ LLM ปัจจุบันที่เขียนข้อความและโค้ดได้ดี พ.ย. 2022 ChatGPT เป็นจุดเปลี่ยนด้านผลิตภัณฑ์ ก่อนหน้านั้นคนไม่คุ้นกับการคุยกับ chatbot ผู้สอนคิดว่าบริษัทที่ปล่อยเองก็คงไม่คิดว่าจะใหญ่ขนาดนี้ และเชื่อว่า tweet ประกาศมีคำพิมพ์ผิด ซึ่งเขาว่าตลกเพราะทุกวันนี้การปล่อย model แต่ละครั้งต้องตรวจถ้อยคำกันเป็นสิบรอบ 2026 ผู้สอนเดาว่าทุกคนใช้ coding agent แทบทุกวัน วิชาจะเล่าว่าเปลี่ยนจากผู้ช่วยสนทนาไปเป็นพฤติกรรมแบบ agent ได้อย่างไร โดยเฉพาะครึ่งหลังของวิชา

4. Tokenization: ระดับคำ ตัวอักษร และคำย่อย (~16:56–27:24)

model เข้าใจตัวเลข ไม่เข้าใจข้อความ ขั้นแรกจึงต้องแบ่งข้อความเป็นหน่วยที่แบ่งต่อไม่ได้ แล้วแทนแต่ละหน่วยด้วยตัวเลข การแบ่งนี้คือ tokenization และแต่ละหน่วยคือ token เช่น "A cute Teddy bear is reading." อาจแบ่งเป็น A / cute / Teddy bear / is / reading / . (6 token) โดยเป้าหมายคือแทนแต่ละ token ด้วยเวกเตอร์ที่มีความหมาย การตัดต้องมี vocabulary (คลังคำ) ที่บอกว่า token ใดใช้ได้ คลังคำต่างกันได้ sequence length (จำนวน token) ต่างกัน และขนาดคลังคำกับความยาวลำดับสัมพันธ์กันแน่น ซึ่งใช้เลือก tokenizer

  • ระดับคำ: ใช้ช่องว่างแบ่ง ข้อดีคือง่าย (โดยเฉพาะภาษาอังกฤษ) และตีความได้ ข้อเสีย: คำมีรูปแปรเยอะ (เอกพจน์ พหูพจน์ เพศ) คลังคำจึงใหญ่ · ไม่มีอะไรรับประกันว่า bear กับ bears จะได้ตัวแทนใกล้กัน ใช้ความรู้จากคำรากเดียวกันไม่ได้ · คำที่ไม่เคยเห็นตอนฝึกไม่มีตัวแทน (out-of-vocabulary)
  • ระดับตัวอักษร: จำนวนตัวอักษรคงที่ จึงไม่มีปัญหาคำนอกคลัง คลังคำเล็ก และทนการพิมพ์ผิดหรือตัวพิมพ์ใหญ่เล็ก (ผู้สอนบอกว่าตัวเองก็พิมพ์ผิดบ่อย) แต่ลำดับยาวขึ้นมาก ความซับซ้อนของ model ขึ้นกับความยาวลำดับ จึงคำนวณช้า และ embedding ของตัวอักษรตีความยากกว่าคำ
  • คำย่อย (subword): อยู่ตรงกลาง แบ่งตามตัวอักษรที่มักมาด้วยกันซึ่งเรียนจากข้อมูล เช่น reading → read + ing ข้อดี: ใช้รากคำร่วมกัน (bear กับ bears มี token bear ร่วม) และเรียนจากข้อมูลจริง ข้อเสีย: ต้องทำงานเพิ่ม และผลขึ้นกับข้อมูลที่ใช้ฝึก tokenizer ซึ่งควรตรงกับเป้าหมายการใช้งาน

5. BPE, token พิเศษ และขนาดคลังคำ (~27:24–37:27)

ในสามแบบ ผู้สอนบอกว่า subword นิยมที่สุดในปัจจุบันแบบทิ้งห่าง และคำที่จะได้ยินบ่อยคือ BPE (Byte Pair Encoding) หลักของ BPE: เริ่มจาก token ชุดแรก (เช่น ตัวอักษรทั้งหมด) หาคู่ที่พบบ่อยที่สุดในข้อมูลฝึก เพิ่ม token ใหม่ที่รวมคู่นั้นลงคลังคำ ทำซ้ำจนได้ขนาดคลังคำที่ต้องการ ตัวอย่างคือ "an" (an idea, an amazing course) ที่ a กับ n มาด้วยกันบ่อย จึงได้ token "an" ข้อดีคือ token เรียนจากข้อมูล ลำดับจึงสั้นลงและ model ทำงานเร็วขึ้น ถ้าข้อมูลที่ใช้มีคำแบบเดียวกับที่ใช้ฝึก ลำดับจะสั้นมาก ทำงานหลายภาษาจึงควรฝึก tokenizer ด้วยข้อมูลที่ครอบคลุมทุกภาษาที่สนใจ ผู้สอนย้ำว่า tokenization เป็นฐานของทุกอย่างที่จะเรียนต่อจากนี้ ส่วนวิธีแทน token ด้วยตัวเลขจะเห็นในอีกราวห้านาที มีคำถามว่า BPE เกี่ยวกับ n-gram ไหม ผู้สอนตอบว่าเป็นคนละเรื่อง BPE เรียน token จากข้อมูลโดยรวมคู่ที่พบบ่อยที่สุดซ้ำไปจนได้ขนาดคลังคำ token พิเศษ:

  • [UNK] (unknown) แทนส่วนที่อยู่นอกคลังคำ เช่น ถ้าคลังคำมีแค่ teddy, cute, bear, [UNK] แล้วเจอ "tedi bear" ที่สะกดแปลก จะได้ [UNK] กับ bear
  • [BOS] / [EOS] บอกจุดเริ่มและจบ ใช้ตอนสร้างข้อความ: ป้อน [BOS] เพื่อบอกให้เริ่ม และ model ปล่อย [EOS] เมื่อจบ เช่น [BOS] What a cute Teddy bear [EOS]
  • padding ทำให้ทุกลำดับยาวเท่ากัน เพื่อประสิทธิภาพ เพราะฮาร์ดแวร์ชอบข้อมูลที่ขนาดเท่ากัน
  • ยังมี token แบบ user / assistant ด้วย ผู้สอนย้ำว่ารายการนี้ไม่ครบ และวิธีเขียนแต่ละที่ต่างกัน

ถามตอบ: ขนาดคลังคำของ LLM ปัจจุบัน หลักแสน เช่น 200,000 รองรับทั้งอังกฤษและภาษาอื่น · tokenizer หลายภาษาทำให้เก่งภาษาเดียวน้อยลงไหม ผู้สอนบอกว่าตอบยาก เพราะภาษาอาจช่วยกัน แต่คลังคำขนาดคงที่ถูกแบ่งให้หลายภาษา ถ้าสนใจภาษาเดียวลำดับอาจยาวขึ้น ส่วนด้านตัวแทนไม่ชัด เช่น ชื่อย่อขององค์กรที่พูดถึงในหลายภาษาอาจได้ประโยชน์

6. One-hot และ word2vec (~37:27–48:26)

วิธีง่ายที่สุดคือถือว่าทุก token ต่างกันหมดแล้วใช้ one-hot เช่น soft = (1, 0, 0) แต่ทุก token จะ ตั้งฉากกัน (dot product เป็น 0) ไม่บอกเลยว่า token เกี่ยวข้องกันอย่างไร สิ่งที่ต้องการคือตัวแทนที่บอกความคล้าย เช่น teddy bear ควรใกล้ soft เพราะตุ๊กตาหมีนุ่ม ส่วน book อาจไม่เกี่ยว เหตุผลคือเราจะใช้ข้อความทำงานบางอย่าง (ทายคำถัดไป จำแนกประเภท) จึงต้องเข้าใจข้อความ word2vec เรียนตัวแทนผ่าน proxy task คืองานที่ฝึกเพื่อให้ได้อย่างอื่น ไม่ใช่เป้าหมายจริง: ทายคำกลางจากคำรอบข้าง (CBOW) หรือทายคำรอบข้างจากคำหนึ่ง (skip-gram) ตัวอย่างบนสไลด์ (ทายคำถัดไป): network ง่าย ๆ คือคูณเมทริกซ์ไปเป็น hidden ขนาด D แล้วคูณอีกครั้งกลับเป็นขนาด V (ขนาดคลังคำ) ประโยค "A cute Teddy bear is reading" คลังคำ 6 คำ "a" เป็น one-hot (1,0,0,0,0,0) ผ่าน network ได้ hidden สองค่า (0.2, 0.9) แล้วได้ความน่าจะเป็นที่รวมกันเป็น 1 ด้วย softmax ป้ายคำตอบคือ "cute" (0,1,0,0,0,0) เป้าหมายคือให้ค่า 0.4 ของ cute ใกล้ 1 ที่สุด ใช้ loss (เช่น cross-entropy) ลงโทษความต่าง แล้วปรับ weight ทำซ้ำกับ cute → Teddy bear และทั้งคลังข้อความ

  • one-hot ขนาด V · hidden (latent) ขนาด D ซึ่งเลือกเองและมักเล็กกว่า V มาก · ความน่าจะเป็นขนาด V

หลังฝึก ผู้เขียนพบว่า hidden representation ตรงกลางมีความหมาย token ที่คล้ายกันได้ตัวแทนคล้ายกัน เช่น teddy bear คู่กับ soft แบบเดียวกับ Persian poetry คู่กับ art และ Paris กับ France แบบเดียวกับ Berlin กับ Germany ผู้สอนจำได้ว่าเป็นวิธีจากราวปี 2013 ข้อจำกัด (สามข้อแรกนักศึกษาตอบ): คำที่ไม่เคยเห็นตอนฝึก (ผู้สอนว่าจริงกับวิธีส่วนใหญ่) · มิติโตตามคลังคำ (ผู้สอนบอกว่าถูก แต่มาจาก tokenizer ที่กำหนดขนาดคลังคำ และเป็นข้อจำกัดของทุกวิธี ไม่เฉพาะ word2vec) · คำหลายความหมาย cute แบบชมกับแบบประชด หรือ bank ริมแม่น้ำกับธนาคาร ได้ตัวแทนเดียวกันไม่ว่าอยู่ประโยคไหน · ผู้สอนเพิ่มอีกข้อ: ลำดับคำไม่มีผล "the child is hugging the Teddy bear" กับ "the Teddy bear is hugging the child" ได้ embedding เหมือนกันทั้งที่ความหมายต่าง

7. RNN และ LSTM (~48:26–55:18)

RNN ซึ่งครองวงการช่วง 2010s คำนวณค่าเพิ่ม คือ hidden state ที่พยายามเก็บความหมายของประโยคที่อ่านมาแล้ว ตัวอย่าง: ใส่ "a" ทาย "cute" แล้วเก็บ hidden state ส่งต่อไปพร้อม "cute" เพื่อทายคำถัดไป ไปเรื่อย ๆ จึงไม่ได้ดูแค่ embedding ของ token แต่ดูความหมายของลำดับที่ผ่านมาด้วย และรู้ลำดับคำ RNN ใช้กับหลายงาน เช่น จำแนกประเภท (อ่านทีละ token แล้วทายความรู้สึกจากสถานะ) จำแนกทีละคำ (คำนามหรือกริยา) หรือสร้างข้อความ ข้อจำกัด: เก็บความหมายทั้งหมดในเวกเตอร์เดียวที่ถูกแก้ไปเรื่อย ๆ จึง จำคำที่อยู่ไกลได้ยาก (long-range dependency) เช่น "My Teddy bear is so cute. It is 3 feet tall." ถ้า "it" อ้างถึงสิ่งที่อยู่ไกลมาก hidden state อาจไม่มีข้อมูลนั้นแล้ว LSTM (Long Short-Term Memory) เพิ่ม cell state อีกตัวที่ตั้งใจพาข้อมูลไปได้ไกลกว่า แต่ผู้สอนบอกว่าก็ยังมีปัญหาเดิม สรุปจุดอ่อน: word2vec ให้ตัวแทนเดียวทุกประโยคและไม่บอกความหมายหลายแบบ · RNN แก้เรื่องลำดับด้วย hidden state แต่มีปัญหาของไกล ซึ่งมาจาก vanishing gradient ตอน backpropagate · และต้องทำทีละ token เพื่อทายตัวถัดไป ฝึกจึงช้ามาก ผลดีในตอนนั้นแต่ไม่ถึงกับยอดเยี่ยม

8. Attention (~55:18–57:16)

ในบรรดาวิธีที่ลองในยุค 2010s ที่โดดเด่นเมื่อมองย้อนกลับคือ attention แนวคิดคือ แทนที่จะพึ่ง hidden state อย่างเดียว ให้ model ต่อตรงไปยัง token ที่ผ่านมา ได้ ตัวอย่างแปล "A cute Teddy bear is reading." เป็นภาษาฝรั่งเศส เมื่อแปลมาได้ส่วนหนึ่งแล้วจะทายคำถัดไป สิ่งที่ช่วยมากคือรู้ว่ากำลังแปลคำไหนของต้นฉบับ RNN แบบเดิมเข้าถึงคำนั้นได้ผ่าน hidden state เท่านั้น attention ให้ต่อตรงไปยัง token ก่อนหน้า แล้วให้ model เรียนเองว่าตัวไหนสำคัญ ผู้สอนย้ำว่าแนวคิดนี้เป็นฐานของทุกอย่างที่จะตามมา

9. Self-attention: query, key, value (~57:16–1:09:35)

บทความปี 2017 เป็นจุดเปลี่ยนเพราะ scale ได้ดีและได้ผลยอดเยี่ยม ใช้ self-attention ซึ่งผู้สอนเรียกว่า attention เวอร์ชันเสริมพลัง ตัวอย่างคือลำดับ "A cute Teddy bear is reading." (Shervine จะยกตัวอย่างละเอียดภายหลัง) แทนที่จะคำนวณตัวแทนของ token จาก hidden state บวกตัวมันเอง จะ คำนวณจากทุก token ในลำดับ มีนักศึกษาถามว่าถ้าทุกตัวต่อถึงกันหมดจะรู้ลำดับคำได้อย่างไร ผู้สอนยอมรับว่าแบบพื้นฐานนี้ ไม่รู้ตำแหน่ง และจะแก้ภายหลัง (position embedding) สัญกรณ์ Q, K, V:

  • query ของ token หนึ่งพยายามหา token อื่นที่ช่วยสร้างตัวแทนที่มีความหมายให้ตัวเอง เช่น query ของ Teddy bear
  • เทียบ query กับ key ของทุก token ด้วยความคล้าย (เช่น dot product) ได้ค่าน้ำหนัก
  • แต่ละ token มี value ตัวแทนของ Teddy bear = ผลรวมถ่วงน้ำหนักของ value ทุกตัว คือ Σᵢ sim(q, kᵢ) vᵢ
  • ตัวอย่าง: "อะไรอธิบาย Teddy bear ได้ดีที่สุด" คำว่า cute อธิบายได้ดี dot product ของ q(Teddy bear) กับ k(cute) อาจจะสูง และ (สมมติว่า) ตัวแทนของ Teddy bear จะพึ่ง cute มาก

Q, K, V ได้จากการ ฉาย (project) ตัวแทนเริ่มต้นของ token ด้วยเมทริกซ์ที่เรียนได้ (นักศึกษาถามว่า T คืออะไร: คือ transpose) เขียนเป็นเมทริกซ์: การดำเนินการนี้คือ softmax(QKᵀ/√d_k) V softmax ทำให้สัมประสิทธิ์รวมกันได้ 1 ผู้สอนเขียนบนกระดาน: Q มีแถว q₁ … qₙ (เช่น 1 = "A" จนถึง n = จุด) คูณ Kᵀ ได้เมทริกซ์ที่ช่อง (i, j) คือ qᵢ·kⱼ แล้วคูณ V ได้แถวที่ i เป็น Σⱼ (qᵢ·kⱼ) vⱼ ตรงกับนิยามข้างบน ผู้สอนบอกว่าสูตรนี้จะเห็นบ่อย และเชื่อว่าเคยมีข้อสอบกลางภาคถามเรื่องนี้ จึงใบ้ว่าสูตรนี้อาจสำคัญ

เสริมจากผู้จัดทำ

ตัวอย่างบนกระดานละ softmax และ √d_k ไว้เพื่อให้เห็นโครงของการคูณเมทริกซ์ ในสูตรจริง ค่า qᵢ·kⱼ แต่ละแถวผ่าน softmax ก่อน จึงเป็นน้ำหนักที่รวมได้ 1 แล้วค่อยคูณ V (ผู้สอนอธิบายส่วนนี้ต่อใน ~1:34:49)

10. สถาปัตยกรรม transformer และ input (~1:09:35–1:16:27)

ทำไมชื่อ "Attention Is All You Need": ตอนนั้น model ส่วนใหญ่เป็นแบบวนซ้ำ (RNN) ที่เก็บ hidden state ไปทีละ token บทความนี้ไม่ทำแบบนั้น แต่ให้ทุก token ต่อตรงกับทุก token ผ่าน self-attention บทความออกมาในบริบท แปลภาษา (เช่น อังกฤษเป็นฝรั่งเศส) มีสองส่วน คือ encoder (ซ้าย) ที่สร้างตัวแทนที่มีความหมายของข้อความต้นทาง และ decoder (ขวา) ที่ใช้ผลของ encoder กับ embedding ภายในของตัวเองเพื่อสร้างคำแปล ทำได้ดี และเป็นฐานของ LLM ปัจจุบัน ผู้สอนย้ำว่าสูตรบนกระดานน่าจะเป็นสูตรที่สำคัญที่สุดของ transformer Input: ข้อความต้นทางถูกตัดเป็น token แล้วแต่ละ token มี embedding ที่เรียนได้ ซึ่งยังไม่รู้บริบท แล้ว บวก position embedding ของตำแหน่งนั้น จึงรู้ว่า token อยู่ที่ไหน ผู้เขียนบทความลองสองวิธี แต่ละวิธีมีข้อดีข้อเสีย

  • position แบบเรียนได้: เป็นธรรมชาติ แต่ถ้าฝึกตำแหน่งไว้ถึง 500 แล้วเจอ input 1,000 token จะแทนตำแหน่งที่เกินไม่ได้
  • position แบบกำหนดไว้ (sin / cos หลายความถี่): ผู้สอนเปรียบกับนาฬิกา เข็มชั่วโมง นาที วินาทีหมุนด้วยความถี่ต่างกัน อ่าน 4:49 ได้จากทุกเข็มรวมกัน เวกเตอร์ที่แต่ละช่องเปลี่ยนด้วยความถี่ต่างกันก็บอกตำแหน่งได้แบบเดียวกัน ข้อดีคือ ตำแหน่งที่ใกล้กันคล้ายกัน ตำแหน่งที่ไกลกันต่างกัน (รายละเอียดอยู่คาบหน้า)

11. Encoder และ decoder (~1:16:27–1:22:16)

Encoder: ชั้นสำคัญคือ self-attention ที่คำนวณตัวแทนของแต่ละ token จากทุก token โดยเรียนเมทริกซ์ฉายไปเป็น Q, K, V แล้วใช้สูตรข้างบน ตามด้วย feed forward neural network ที่ฉายไปมิติสูงขึ้นพร้อม activation function เพื่อเรียนความไม่เป็นเชิงเส้น ปลาย encoder ได้ตัวแทนที่มีความหมายของทุก token ซึ่งเป็นฟังก์ชันของทุก token ในลำดับ Decoder: ป้อน token พิเศษ [BOS] บวก position ของตำแหน่งแรก แล้วผ่านสองชั้น attention:

  1. self-attention กับตัวเองและทุก token ที่สร้างมาแล้ว (ตอนเริ่มมีแค่ [BOS])
  2. attention อีกแบบ ที่ให้ token ที่สร้างมาแล้วคุยกับ token ของต้นฉบับ: query มาจากฝั่งที่สร้างมาแล้ว ส่วน key และ value มาจาก encoder (ในภาพมีลูกศรหนึ่งเส้นจากฝั่ง decoder และสองเส้นจาก encoder) เพราะถามว่าจะแสดง token นี้เป็นฟังก์ชันของ token ทั้งหมดในต้นฉบับอย่างไร

แล้วผ่าน feed forward อีกครั้ง ได้ตัวแทนของ token ที่ป้อนเข้า ฉายไปยังขนาดคลังคำ ได้ความน่าจะเป็นของ token ถัดไป เลือก token แล้วใส่กลับเข้า decoder ทำซ้ำแบบ autoregressive ผู้สอนบอกว่าคาบแรกนี้น่าจะเป็นหนึ่งในคาบที่ยากที่สุดในแง่จำนวนแนวคิด และถ้ารู้สึกว่าเยอะก็เป็นเรื่องปกติ

12. เทคนิคการคำนวณ (~1:22:16–1:27:35)

  • Residual connection (ตอบคำถามนักศึกษาเรื่องลูกศรที่รวมกันในภาพ): ช่วยให้ model ลึกเรียนได้ดีขึ้น ส่ง feature ผ่านไปตรง ๆ แทนที่ทุกชั้นต้องแปลง ผลลัพธ์ของชั้นคือ x + f(x) ไม่ใช่ f(x) ผู้สอนมองว่าเป็นการแก้ x ไม่ใช่เปลี่ยน x ทั้งหมด ช่วยการ backpropagation
  • Layer normalization: ปรับค่า activation ให้เป็นมาตรฐาน ช่วยให้ลู่เข้า
  • Masked self-attention ใน decoder: ให้ token คุยได้แค่กับ token ที่สร้างมาแล้ว เพราะ token ที่ยังไม่สร้างคุยด้วยไม่ได้
  • Multi-head attention: เรียนการฉาย Q, K, V หลายชุด เปรียบกับ CNN ที่ใช้ filter หลายตัว ได้หลายวิธีในการเรียนสิ่งเดียวกัน โดยทั่วไปมี h หัว
  • Dropout (ใช้กว้างขวาง ไม่เฉพาะ transformer): ตอนฝึกตั้งใจตัดบางหน่วยด้วยความน่าจะเป็นหนึ่ง เพื่อไม่ให้ model พึ่ง feature บางตัวมากเกินไป ช่วยให้ทั่วไปขึ้น
  • Label smoothing: แทนที่จะบังคับให้ทาย "day" ใน "what a nice day" เต็ม 100% ยอมให้คำอื่นมีโอกาสด้วย เพราะภาษาต่อได้หลายแบบ (nice class, nice evening) ผู้สอนยกตัวอย่างว่าป้ายที่ต้องการอาจเป็น 90% และอีก 10% แบ่งให้คำอื่นในคลังคำ ช่วยให้ model ทั่วไปขึ้นเล็กน้อย และผู้เขียนบทความพบว่ายังทำให้ค่าวัดการแปลอย่าง BLEU ดีขึ้น

13. ตัวอย่างครบวงจร (~1:27:35–1:44:28)

Shervine รวมทุกอย่างในตัวอย่างเดียว: แปล "A cute teddy bear is reading." (บทความเดิมแปลเป็นฝรั่งเศสและเยอรมัน) แบ่ง token แบบหนึ่งเพื่อแสดงว่าการแบ่งเลือกได้ แล้วเติม [BOS] และ [EOS] ฝั่ง encoder:

  1. lookup table ของ embedding ที่เรียนได้ บวก position embedding แบบ sin/cos ขนาดเท่ากัน (d_model) แบบบวก ได้ embedding ที่อย่างน้อยครึ่งหนึ่งเรียนได้ (ตำแหน่งจะเรียนด้วยหรือไม่ขึ้นกับการออกแบบ) เรียงเป็นเมทริกซ์ n แถว
  2. ฉายด้วย W_Q, W_K, W_V ได้ Q, K, V แล้วใช้สูตร ได้เมทริกซ์ขนาดเดียวกับ V
  3. ขนาด: ลำดับยาว n · embedding ขนาด d_model · W_Q เป็น d_model × d_q (เช่นเดียวกับ W_K, W_V) · Q, K, V มี n แถว และ d_q, d_k, d_v คอลัมน์ · ต้องมี d_q = d_k จึงคูณกันได้
  4. QKᵀ เป็น n × n แต่ละช่องคือความคล้ายของ query หนึ่งกับ key หนึ่ง แต่ละแถวผ่าน softmax ได้การกระจายความน่าจะเป็นบน key แล้วใช้ถ่วงน้ำหนัก value · หารด้วย √d_k เพราะขนาด d_k มีผลต่อความแปรปรวนของผลรวม หารด้วยส่วนเบี่ยงเบนมาตรฐานเพื่อให้ปกติ
  5. multi-head: ทำ h ครั้งขนานกัน ต่อผลทั้งหมด แล้วฉายด้วย W_O จากขนาด h·d_v กลับเป็น d_model ผู้สอนชี้ว่าใน transformer หลายการดำเนินการรักษาขนาด d_model ไว้
  6. feed forward: หนึ่งชั้นซ่อน ฉาย d_model ไปเป็น d_ff ซึ่งมักใหญ่กว่า เพื่อเรียนตัวแทนที่ซับซ้อน
  7. ทำทั้งหมด N ครั้ง ในบทความ N = 6 ได้ตัวแทนของแต่ละ token ที่รู้บริบทและเรียนมาแล้ว

ฝั่ง decoder: ใส่ [BOS] เปิด lookup table บวก position ส่งเข้า masked self-attention (causal: ทุก token ดูตัวเองและตัวก่อนหน้า) แล้ว cross-attention ที่ query เป็น token ของ decoder ส่วน key และ value มาจาก output embedding ของ encoder ชั้นสุดท้าย ซึ่งทุก block ของ decoder ได้รับ แล้วผ่าน feed forward, linear และ softmax ได้การกระจายบนคลังคำ คาบหน้าจะพูดถึงวิธีเลือกคำ ตัวอย่างนี้เลือกค่าสูงสุด ได้ "un" ใส่กลับ ได้คำของ teddy bear (ours en peluche) ทำต่อจนได้ [EOS] จึงหยุด ถามตอบช่วงท้าย:

  • ถ้าต้องสรุปว่าอะไรทำให้ได้ผล: ถ้าให้ Shervine ตอบเอง ตามชื่อบทความ แก่นคือ attention ที่คาบหน้า ๆ จะเห็นว่าส่วนอื่นหลายส่วนถูกตัดทิ้ง เหลือบางส่วนที่ซ้ำไปเรื่อย ๆ และ feed forward ที่เก็บพารามิเตอร์ส่วนใหญ่ของ network และเป็นที่ที่การเรียนรู้เกิด ที่เหลือคือเทคนิคช่วยให้เรียนดีขึ้น บวกคุณภาพของข้อมูล
  • mask: เป็นเทคนิคการคำนวณ ใช้เมทริกซ์สามเหลี่ยมที่ปิดการเชื่อมบางเส้นของ self-attention ตอนฝึก ใส่ −∞ ซึ่ง softmax แปลงเป็น 0 ผู้สอนคิดว่าภาพในใจที่พอคือ ตัดการเชื่อมจาก token หนึ่งไปยังทุกตัวที่ตามหลัง
  • softmax หลายที่: softmax ใน self-attention และ cross-attention ทำหน้าที่ฉาย query ไปบนพื้นที่ของ key ส่วน softmax ชั้นสุดท้ายใช้ทาย token ถัดไป ฟังก์ชันเดียวกันแต่คนละหน้าที่
  • [BOS] ในคำแปล: มีเป็น token แรกของ input ของ decoder เพื่อให้ทายตัวถัดไป ไม่ได้ออกมาเป็น output สิ่งที่ต้องดูคือ [EOS] ที่บอกว่าจบ

ผู้สอนปิดว่าทั้งหมดนี้ยังอยู่แค่ปี 2017 คาบต่อ ๆ ไปจะดูวิธีฝึก model แบบนี้ และครึ่งหลังจะดูว่าใช้ขับ agent และระบบต่าง ๆ อย่างไร

ข้อที่ควรเข้าใจให้ตรง

ผลตรวจของผู้จัดทำ: "พารามิเตอร์ส่วนใหญ่อยู่ใน feed forward" ถูกในระดับ encoder layer ของ model base (feed forward 2·512·2048 ≈ 2.1 ล้าน เทียบกับ attention 4·512² ≈ 1.05 ล้าน) แต่ใน decoder layer ที่มี attention สองชุด สัดส่วนราวครึ่งต่อครึ่ง และทั้ง model base (65 ล้าน) ส่วน feed forward ราว 39% · เรื่อง tweet ของ ChatGPT ที่พิมพ์ผิดไม่พบหลักฐาน

เสริมจากผู้จัดทำ: วิเคราะห์เพิ่ม
  • ลำดับเหตุผลของคาบนี้ใช้เป็นโครงสอนได้ดี: one-hot ไม่มีความหมาย → word2vec ไม่มีบริบทและลำดับ → RNN มีลำดับแต่ลืมของไกลและช้า → attention ต่อตรง → self-attention ต่อทุกตัวพร้อมกัน → ต้องเติมตำแหน่ง
  • ค่าในบทความที่ผู้สอนไม่ได้บอกตัวเลข: d_model 512, h 8, d_k = d_v 64, d_ff 2048, dropout 0.1, label smoothing 0.1 (ผลตรวจของผู้จัดทำ)
  • ข้อมูลเพิ่มจากบทความ: ผู้เขียน 8 คน ระบุว่ามีส่วนเท่ากัน ลำดับชื่อสุ่ม (ผู้จัดทำ)
  • LLM แบบ GPT ใช้แค่ฝั่ง decoder (ความรู้ทั่วไป) ซึ่งตรงกับที่ผู้สอนบอกว่าคาบหลัง ๆ ส่วนประกอบหลายอย่างจะถูกตัดทิ้ง

Key Takeaways

1.ยุค 2010s ใช้ model เฉพาะงานแบบ RNN จุดเปลี่ยนคือ transformer (2017) ที่ scale ได้ดี แล้วจึงเป็น LLM, ChatGPT (2022) และ agent
2.tokenization แบบคำย่อย (BPE) สมดุลระหว่างขนาดคลังคำกับความยาวลำดับ คลังคำ LLM ปัจจุบันหลักแสน
3.word2vec ได้ embedding ที่มีความหมายจากงานแทน แต่ไม่สนบริบทและลำดับ RNN สนลำดับแต่ลืมของไกลและต้องทำทีละ token
4.self-attention ให้ทุก token เป็นผลรวมถ่วงน้ำหนักของ value ทุกตัว ด้วยสูตร softmax(QKᵀ/√d_k)V และต้องเติม position embedding เพื่อรู้ลำดับ
5.transformer เดิมเป็น encoder–decoder ซ้อน 6 ชั้น มี masked self-attention และ cross-attention (Q จาก decoder, K / V จาก encoder) พร้อม residual, layer norm, multi-head, dropout, label smoothing
