Tokens vs Embeddings – what are they + how are they different? — Annie Sexton

✍️ Annie Sexton (YouTube)📅 เผยแพร่ 2025-05-29⏱ 6:52🎞 caption ภาษาอังกฤษอัตโนมัติ (ASR) 171 บรรทัด📝 เรียบเรียงใหม่ด้วยคำของผู้จัดทำ ครบทุกประเด็นและตัวเลข🖼 ภาพนิ่งจากคลิป 7 ภาพ + ภาพ SVG วาดเอง 2 ภาพ 🔗 คลิปต้นฉบับ (YouTube)

📋 บทสรุปย่อ

บทสรุปย่อ: คลิปสั้นที่แยกสองคำที่คนสับสนบ่อยใน LLM: embedding คือเวกเตอร์ (ชุดตัวเลขหลายตัว) ที่แทนความหมาย ส่วน token คือตัวเลขตัวเดียวที่เป็นแค่ ID ไม่มีความหมายในตัว ทุก token ชี้ไปที่ embedding หนึ่งตัวเป็นจุดเริ่ม แล้วโมเดลปรับ embedding ตามบริบท (คำเดียวกันหลายความหมาย เช่น train) ตัวอย่างหลักคือ king − man + woman = queen ด้วยเวกเตอร์ 2 มิติที่บวกลบได้จริง และปิดท้ายด้วยนิยามใหม่: embedding ไม่ได้เก็บความหมาย แต่บอกว่าความหมายต่าง ๆ อยู่ตรงไหนเมื่อเทียบกัน

โหมดของเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ (license มาตรฐานของ YouTube, ตรวจ 2026-10-11) อ่านจาก caption อังกฤษอัตโนมัติ ตัวเลขทุกตัวเทียบกับสไลด์ในคลิป · คลิปเผยแพร่ 2025 อยู่ในช่วงความรู้ของผู้จัดทำ จึงไม่ได้ค้นเว็บเพิ่ม ข้อความที่ผู้จัดทำเติมเองติดป้าย "ผู้จัดทำ" ทุกจุด และจุดที่คลิปพูดง่ายเกินไปรวมไว้ในส่วนที่ 7

🧭 สรุปเชิงลึก

สองคำ สองหน้าที่: token กับ embedding ต่างก็เป็น "ตัวเลขที่แทนคำ" แต่ token ใช้ตัวเลขตัวเดียวทำหน้าที่เป็น ID ประจำคำในแค็ตตาล็อกของโมเดล เลขใกล้กันไม่ได้แปลว่าคำใกล้กัน ส่วน embedding ใช้ตัวเลขหลายร้อยตัว (ตามคลิป) ที่ตำแหน่งมีความหมาย คำที่สัมพันธ์กันจึงคำนวณกันได้ เช่น king − man + woman ได้ queen

เส้นทางในโมเดล: พิมพ์ prompt → แต่ละคำกลายเป็น token → token ชี้ไปที่ embedding หนึ่งตัว → โมเดลทำงานกับ embedding เพื่อทายส่วนถัดไปของประโยค แต่ embedding ของ token เป็นแค่จุดเริ่ม คำที่มีหลายความหมาย (train = ฝึก / รถไฟ) หรือคำที่ต้องรู้ว่าหมายถึงใคร (she = Annie) ต้องอาศัยบริบท โมเดลดูคำรอบข้างแล้วปรับเป็น embedding ใหม่ที่ขึ้นกับบริบท

นิยามที่กว้างขึ้นตอนท้าย: embedding ตั้งต้นของ token มักไม่ได้มีความหมายในตัว และไม่ใช่ค่าเฉลี่ยของสองความหมาย มันคือเวกเตอร์ที่ช่วยทายคำรอบข้างได้ดีที่สุดโดยเฉลี่ย ทั่วข้อมูลฝึก ภาษาไม่ได้เป็นแค่ก้อนความหมายแยกกัน แต่คือความสัมพันธ์ระหว่างก้อนเหล่านั้น embedding จึงบอกตำแหน่งของความหมายเมื่อเทียบกัน ไม่ได้เก็บความหมายเอง

1. Embedding คือเวกเตอร์ที่มีความหมาย (~0:00–1:18)

ผู้สอนเปิดว่าคนที่ใช้ LLM มักเจอคำว่า token กับ embedding และพอรู้คร่าว ๆ ว่า "เป็นตัวเลขที่แทนอะไรสักอย่าง" คลิปนี้จะอธิบายว่าแต่ละคำคืออะไร ต่างกันอย่างไร และส่วนที่น่าสนใจที่สุดคือทั้งสองเกี่ยวกันอย่างไร

เริ่มจาก embedding: embedding คือเวกเตอร์ที่แทนบางอย่าง ส่วนเวกเตอร์ก็คือชุดตัวเลข (array) เท่านั้น พิกัด x, y เป็นเวกเตอร์ 2 มิติ พิกัด x, y, z เป็นเวกเตอร์ 3 มิติ และจำนวนมิติไม่มีขีดจำกัด เวกเตอร์เป็นแนวคิดพื้นฐานทางคณิตศาสตร์ที่ใช้ใน linear algebra, เรขาคณิต, ชีววิทยา, กราฟิก ฯลฯ

เวกเตอร์เป็นแค่แนวคิดทางคณิตศาสตร์ ส่วน embedding คือเวกเตอร์ที่มีความหมาย แทนอะไรก็ได้ในทางเทคนิค แต่คลิปนี้เน้นคำ เพราะ AI ที่เราใช้บ่อยที่สุดน่าจะเป็น LLM ซึ่งเป็นเรื่องของภาษา

2. king − man + woman = queen ด้วยเวกเตอร์ 2 มิติ (~1:18–2:44)

ตัวเลขแทนคำได้อย่างไร ผู้สอนใช้ตัวอย่างดังคือ king − man + woman = queen ซึ่งไม่ใช่คณิตศาสตร์จริง แต่เข้าใจได้ตามสัญชาตญาณ แล้วแทนแต่ละคำด้วยเวกเตอร์ 2 มิติ:

  1. king − man = (1, 9) − (1, 0) = (0, 9) ในรายการไม่มีคำไหนเป็น (0, 9) สไลด์จึงเขียนว่า ???
  2. (0, 9) + woman = (0, 9) + (9, 0) = (9, 9) ซึ่งเป็นเวกเตอร์ของ queen พอดี

ในตัวอย่างง่าย ๆ นี้ ความหมายของ queen, king, woman และ man ถูกจับไว้ด้วยคุณสมบัติสองอย่าง ซึ่งเรียกว่าสองมิติ แต่สองมิติจับความหมายเต็มของคำไม่ได้ embedding จึงมักมีหลายร้อยมิติ ทำให้มีความสัมพันธ์กับคำอื่นที่ซับซ้อนกว่านี้มาก ผู้สอนบอกว่าจะกลับมาเรื่องนี้อีก (ผู้จัดทำ: น่าจะหมายถึงส่วนที่ 5–6)

3. Token: ตัวเลขตัวเดียวที่เป็นแค่ ID (~2:44–3:30)

เวกเตอร์และ embedding เป็นแนวคิดที่เจอทั่ว machine learning แต่ token ผูกกับงานภาษาธรรมชาติ (NLP) และ LLM เป็นหลัก token ก็เป็นตัวเลขที่แทนคำเหมือน embedding แต่ embedding อาจใช้ตัวเลขหลายร้อยตัวอธิบายคำหนึ่งคำ ส่วน token ใช้ตัวเลขตัวเดียว

แล้วทำไมยังต้องมี embedding? เพราะทุกคำที่โมเดลเคยฝึกจะถูกจดลงแค็ตตาล็อกและได้เลขเฉพาะของตัวเอง เลขนี้เป็นเหมือน ID ไม่มีความหมายทางภาษา คำสองคำอาจได้เลขที่ใกล้กันมากทั้งที่ไม่เกี่ยวกันเลย

สไลด์ใช้ประโยค "The quick brown fox jumps over the lazy dog." ได้ 10 ตัวเลข: 9 คำ + จุดท้ายประโยค (13) (ผู้จัดทำ: คลิปไม่ได้บอกว่าใช้ tokenizer ตัวไหน จึงตรวจเลขไม่ได้)

4. Token ชี้ไปที่ embedding แล้วโมเดลทำงานกับ embedding (~3:30–4:02)

ทุก token ชี้ไปที่ embedding หนึ่งตัว (token นี้ = embedding นี้) เมื่อพิมพ์ prompt ใน ChatGPT แต่ละคำจะถูกแปลงเป็น token แล้วแปลงต่อเป็น embedding และโมเดลทำงานกับ embedding เพื่อทายส่วนถัดไปของประโยค ซึ่งก็คือคำตอบของ prompt

(ผู้จัดทำ: ก่อนสไลด์นี้ที่ ~3:36 มีภาพขยายเลข 3290 ของ dog ตัวเดียว ตอนอธิบายว่า token หนึ่งตัวชี้ไปที่ embedding หนึ่งตัว · การที่ "แต่ละคำเป็น token" เป็นภาพแบบง่ายของคลิป ดูส่วนที่ 7)

ตัวอย่างบนสไลด์: "Write an email to my manager asking for a raise" → [10253, 470, 4095, 407, 616, 4964, 16120, 329, 257, 10788] → embedding ([…]) สิบตัว

ผู้สอนทิ้งท้ายว่า "ยังมีบางอย่างขาดอยู่" ซึ่งเป็นเรื่องของส่วนถัดไป: ถ้าคำหนึ่งได้ token เดียวและ embedding เดียว แล้วคำที่มีหลายความหมายล่ะ

5. คำเดียวหลายความหมาย: embedding ต้องปรับตามบริบท (~4:02–5:01)

ถ้า embedding คือตัวเลขที่แทนความหมายหนึ่ง คำที่มีหลายความหมายจะมี token เดียวและ embedding เดียวได้อย่างไร ตัวอย่าง: train ใน "I train my dog." หมายถึงฝึก แต่ในประโยคที่สองบนสไลด์ (midnight train) หมายถึงรถไฟ มนุษย์รู้ได้จากบริบท ความหมายของคำมักขึ้นกับคำรอบข้าง เหมือนที่เรารู้ว่า she ในประโยค "Annie couldn't remember where she had left her keys." หมายถึง Annie

LLM ก็ใส่ใจบริบทเหมือนกัน: token ชี้ไปที่ embedding ตัวเดียวเสมอ และนั่นเป็นแค่จุดเริ่ม จากนั้นโมเดลดูคำรอบ ๆ แล้วปรับ embedding นั้น เป็นตัวแทนที่ไวต่อบริบทมากขึ้น ได้ embedding ใหม่ตามบริบท

ผู้จัดทำ: คลิปไม่ได้เอ่ยชื่อกลไก ส่วนที่ "ดูคำรอบข้างแล้วปรับ" นี้คือ attention ในบท 7.2 ของ ZVect

6. นิยามใหม่: embedding ไม่ได้เก็บความหมาย แต่บอกตำแหน่งเทียบกัน (~5:01–6:12)

ผู้สอนขอให้หยุดคิดตรงนี้: ถึงจะพูดเรื่องภาษา แต่เครื่องเข้าใจแค่ตัวเลข embedding ตั้งต้นของ token มักไม่ได้มีความหมายอะไร เป็นแค่ตัวเลข และไม่ใช่ค่าเฉลี่ยระหว่างสองความหมายของคำ

พูดให้เจาะจงขึ้น embedding คือเวกเตอร์ที่พิสูจน์แล้วว่ามีประโยชน์ที่สุด โดยเฉลี่ยทั่วข้อมูลฝึก ในการช่วยโมเดลทายคำรอบข้าง ซึ่งขยายภาพจากตอนแรกที่บอกว่า embedding คือชุดตัวเลขที่แทนสิ่งต่าง ๆ อย่างคำ

ผู้เชี่ยวชาญ deep learning เข้าใจว่าภาษาไม่ใช่แค่การรวมก้อนความหมายที่แยกกัน แต่คือความสัมพันธ์ระหว่างก้อนเหล่านั้น สิ่งที่ผู้สอนต้องการสื่อคือ embedding ไม่ได้เก็บความหมาย แต่บอกว่าความหมายต่าง ๆ อยู่ตรงไหนเมื่อเทียบกัน (ผู้สอนเรียกประโยคนี้ว่าเป็นบทกวี)

ปิดคลิป (~6:12–6:52): ยังมีเรื่อง token อีกมาก เช่นขั้นตอน tokenization และโมเดลรับมือกับคำพิมพ์ผิด คำที่แต่งขึ้น หรือคำสแลงอย่างไร ถ้าอยากรู้ให้บอกในคอมเมนต์ อาจทำคลิปต่อ และขอหัวข้อเกี่ยวกับ deep learning / machine learning / AI ที่อยากให้ทำ

7. จุดที่คลิปพูดง่ายเกินไป และการใช้ใน ZVect (ผู้จัดทำ)

จุดที่คลิปพูดง่ายเกินไป (ผู้จัดทำ):

  • "ทุกคำได้เลขของตัวเอง": tokenizer ของ LLM ตัดเป็น subword ไม่ใช่ทั้งคำเสมอ คำยาวหรือคำแปลกแตกเป็นหลาย token (บท 3.2 BPE และ 3.3 Tokenizer ของ GPT) ตัวอย่างบนสไลด์ใช้ประโยคที่ทุกคำบังเอิญเป็น token เดียว
  • "หลายร้อยมิติ": เป็นตัวเลขกลม ๆ ของคลิป embedding ใน LLM ขนาดใหญ่มักมีหลายพันมิติ (ความรู้ทั่วไป)
  • สไลด์ตอนท้ายเป็นภาพคร่าว ๆ: ตัวสไลด์เองเขียนหมายเหตุว่าของจริงซับซ้อนกว่ามาก (ปรับหลายชั้น ไม่ใช่ดูแค่คำเดียว)
  • เลข token บนสไลด์: ไม่ได้บอก tokenizer ผู้จัดทำจึงไม่นำเลขชุดนี้ไปใช้เป็นค่าจริงในบทเรียน
  • ไวยากรณ์บนสไลด์: "An embedding are the vectors…" (สไลด์เขียนแบบนี้) ความหมายไม่เปลี่ยน

ใช้ใน ZVect (ผู้จัดทำ):

  • บท 3.4 Token ID: "เลขเป็นแค่ ID เลขใกล้กันไม่ได้แปลว่าคำเกี่ยวกัน" ตรงกับบทนี้ เพิ่มเป็นแหล่งยืนยันได้
  • บท 3.7 Embedding matrix: token → embedding หนึ่งตัว (หยิบแถว) และประโยค prompt → token → embedding
  • บท 3.9 Latent space: ตัวอย่าง king (1, 9) − man (1, 0) + woman (9, 0) = queen (9, 9) เป็นเลขจำนวนเต็มที่คิดในใจได้ เหมาะเป็นค่าเริ่มต้นแบบ 2 มิติ
  • บท 7.1 / 7.2: embedding ตั้งต้นเป็นจุดเริ่ม แล้วปรับตามบริบท (train, she)
  • คำถามของเจ้าของโปรเจกต์ "ทำไมไม่มีหัวข้อ Embedding": คลิปนี้แยก Token กับ Embedding เป็นสองเรื่องชัดเจน สนับสนุนการแยกบท 3 เป็นบท Token และบท Embedding

Key Takeaways

  1. embedding คือเวกเตอร์ (ชุดตัวเลขหลายตัว) ที่ตำแหน่งมีความหมาย ส่วน token คือตัวเลขตัวเดียวที่เป็นแค่ ID
  2. เลข token ใกล้กันไม่ได้แปลว่าคำเกี่ยวกัน จึงต้องมี embedding
  3. king (1, 9) − man (1, 0) + woman (9, 0) = (9, 9) = queen: ความสัมพันธ์ของคำกลายเป็นการบวกลบเวกเตอร์
  4. token ชี้ไปที่ embedding ตั้งต้นหนึ่งตัว แล้วโมเดลปรับตามบริบท (train ฝึก / รถไฟ, she = Annie)
  5. embedding ไม่ได้เก็บความหมาย แต่บอกว่าความหมายอยู่ตรงไหนเมื่อเทียบกับความหมายอื่น
