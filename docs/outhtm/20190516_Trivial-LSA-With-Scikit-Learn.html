3. ขั้น 2: CountVectorizer ได้ bag of words = X (~1:11–1:59)

ใน scikit-learn document-term matrix สร้างได้ด้วยโมเดล CountVectorizer จากโมดูล sklearn.feature_extraction.text ผู้บรรยายสร้าง CountVectorizer แล้วใช้มัน fit แล้ว transform body เป็น bag of words เขาบอกว่าคำนี้ในงาน NLP หมายถึงรูปที่ง่ายที่สุดของ document-term matrix กระบวนการนี้แปลงแต่ละเอกสารเป็นเวกเตอร์ เมทริกซ์ประกอบด้วยเวกเตอร์หนึ่งตัวต่อเอกสาร ~1:11–1:46 โค้ด (Cmd 12) ถอดตรงตัว:

from sklearn.feature_extraction.text import CountVectorizer

vectorizer = CountVectorizer()

Key Takeaways

1.โค้ด LSA ทั้งหมดของคลิปมีสี่บรรทัดหลัก: CountVectorizer(), .fit_transform(body), TruncatedSVD(n_components=2), .fit_transform(bag_of_words) สิ่งที่คำนวณคือ X ≈ U₂Σ₂V₂ᵀ และ Z = U₂Σ₂ = X V₂ (สมการของผู้จัดทำ)
2.ตาราง topic-encoded data (1.6949 / 0.2995, 1.5159 / −0.7691 ×2, 1.2662 / 1.4406) ได้จากผลรวมน้ำหนักของคำในแต่ละเอกสาร ผู้จัดทำแทนค่าครบทุกช่องและรันซ้ำได้ตรง
