บทสรุปย่อ

คลิปสั้น 3 นาทีครึ่ง ตอนแรกจากห้าตอนของ Databricks Academy โดย Joshua Cook ปูศัพท์พื้นฐาน (NLP, document, body, dictionary, topic, latent) แล้วอธิบาย Latent Semantic Analysis (LSA) ว่าเป็นเทคนิค NLP แบบ unsupervised ที่แทนข้อความด้วย latent feature (คลิปเรียกว่า topic) และได้ผลพลอยได้คือลดมิติ ขั้นตอนมีสองขั้น: สร้าง document-term matrix แล้วทำ singular value decomposition (SVD) กับเมทริกซ์นั้น ตัวอย่างคือประโยคสั้นสี่ชิ้นกับคำเก้าคำ รายงานฉบับนี้เขียนทุกอย่างที่คลิปพูดเป็นสมการให้เห็น: เมทริกซ์ X ขนาด 4 × 9 ของคลิป เวกเตอร์ของสี่เอกสาร และสมการ SVD แบบตัดเหลือ k ตัว X ≈ U_k Σ_k V_kᵀ (สมการ SVD ไม่ได้อยู่บนจอ เป็นของผู้จัดทำ ตัวเลขคำนวณซ้ำแล้ว) พร้อมแก้ป้ายแถวที่สไลด์พิมพ์ผิด ("the quick red fox" ต้องเป็น "the quick red dog") ที่มาของเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ (license มาตรฐานของ YouTube) ข้อความบนสไลด์และตัวเลขถอดตามภาพ

โหมดเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ แบบวิเคราะห์เชิงลึก (license มาตรฐานของ YouTube) ข้อความบนสไลด์ ตาราง และเวกเตอร์ถอดตรงตามภาพทุกตัว สมการ SVD และตัวเลขทุกตัวที่ไม่ได้อยู่บนจอเป็นของผู้จัดทำ คำนวณซ้ำด้วย numpy/scikit-learn (recompute_toy.py)

สรุปเชิงลึก

ศัพท์ตั้งต้น (0:17–0:58): สไลด์ค่อย ๆ เพิ่มนิยามหกคำ NLP คือกลุ่มเทคนิคที่ใช้ดึงความหมายจากข้อความ document คือกลุ่มคำชุดหนึ่ง และเป็น "แถว" ของชุดข้อมูล body คือกลุ่มของ document ทั้งชุด dictionary คือเซตของคำทุกคำที่อยู่ในอย่างน้อยหนึ่ง document topic คือกลุ่มคำที่ปรากฏร่วมกัน และ latent คือ feature ที่ "ซ่อน" อยู่ในข้อมูล วัดตรง ๆ ไม่ได้ เป็นแก่นของข้อมูลแต่ไม่ใช่ feature ดั้งเดิมของชุดข้อมูล ผู้บรรยายเสริมว่าสิ่งที่วัดได้คือคำ ส่วนสิ่งที่เราสนใจคือ latent feature ที่แทนบางอย่างที่เป็นแก่นของชุดข้อมูล

LSA คืออะไร (1:05–1:36): เป็นทั้งเทคนิค NLP และ unsupervised learning ต่างจาก supervised learning ตรงที่ไม่มี target หรือ label จุดมุ่งหมายคือแทนข้อความด้วย topic หรือ latent feature และผลพลอยได้คือลดมิติของชุดข้อมูลข้อความ

สองขั้น (1:38–1:50): แผนภาพวาดวงกลมสี่วง ข้อความดิบ → document-term matrix → SVD → ข้อมูลที่เข้ารหัสด้วย topic โดยกรอบเส้นประชื่อ "Latent Semantic Analysis" ครอบแค่สองวงกลาง ผู้บรรยายพูดว่า LSA ประกอบด้วยสองขั้นนี้

ขั้นแรก document-term matrix (1:50–2:40): แนวคิดคือเอกสารแทนได้ด้วยจุดใน Euclidean space หรือเวกเตอร์ ตารางในสมุดโน้ตมี 4 แถว (เอกสาร) × 9 คอลัมน์ (brown, dog, fox, lazy, quick, red, slow, the, yellow) ค่าเป็น 0 หรือ 1 เพราะไม่มีคำซ้ำในประโยค แถวแรก "the quick brown fox" = (1, 0, 1, 0, 1, 0, 0, 1, 0) ผู้จัดทำเขียนเป็นสมการ X ∈ ℝ^{4×9} ที่ X_ij = จำนวนครั้งของคำ j ในเอกสาร i (สมการ 3–4) ป้ายแถวที่สามบนตารางพิมพ์ผิด: เขียนว่า "the quick red fox" แต่ค่าในแถว (dog = 1, fox = 0) คือ "the quick red dog" ซึ่งตรงกับเซลล์ถัดไปและกับโค้ดของตอนที่ 2 ผู้จัดทำลองคำนวณแบบที่ป้ายบอก ได้ topic-encoded data คนละชุดกับที่สมุดโน้ตตอนที่ 2 แสดง (เอกสารแรกจะได้ 1.8216 แทน 1.6949 ที่สมุดโน้ตตอนที่ 2 แสดง) จึงยืนยันว่าข้อมูลจริงคือ dog

ขั้นที่สอง SVD (2:40–3:06): สไลด์บอกสี่ข้อ: SVD คล้ายกับ PCA, ลดมิติของข้อมูลเดิม, แปลงข้อมูลให้เข้ารหัสด้วยตัวแปรแฝง และใน LSA ตัวแปรแฝงคือ topic คลิปไม่มีสูตรของ SVD เลย ผู้จัดทำเขียนให้ (สมการ 7–10): X = U Σ Vᵀ, ตัดเหลือ k = 2 ได้ X ≈ U₂ Σ₂ V₂ᵀ และข้อมูลที่เข้ารหัสด้วย topic คือ Z = U₂ Σ₂ = X V₂ ค่าเอกพจน์ของตัวอย่างนี้คือ σ = 3.0119, 1.8298, 1.4142, 1.2571 ผลรวม σ² = 16 = จำนวนเลข 1 ในเมทริกซ์ ถ้าเก็บ k = 2 จะเก็บ "พลังงาน" ไว้ 77.6 % ส่วนคำว่า "คล้าย PCA" ต้องเข้าใจว่า PCA ลบค่าเฉลี่ยของแต่ละคอลัมน์ก่อน แต่ LSA ในทางปฏิบัติ (TruncatedSVD ของ scikit-learn) ไม่ลบ ผลคือ topic แรกของตัวอย่างนี้ถูกคำว่า "the" ครอง (ซึ่งตอนที่ 2 แสดงให้เห็น)

ตรวจแล้ว: 9 ข้อ ยืนยัน 5, ยืนยันบางส่วน 3, ขัดแย้ง 1 (ป้ายแถวบนสไลด์) ที่คลิปยังไม่มี: การถ่วงน้ำหนัก (TF-IDF อยู่ในตอนที่ 4) การเลือก k (scikit-learn แนะนำ 100 สำหรับ LSA, Wikipedia บอกราว 100–300) และวิธีฉายเอกสารหรือคำค้นใหม่ X′ = X V_k (คู่มือ scikit-learn) เอาไปใช้: ตัวอย่าง 4 × 9 นี้เล็กพอให้ตรวจด้วยมือทุกช่อง เหมาะเป็นชุดทดสอบของ SVD ที่เขียนเอง (ดูหัวข้อ 10)

3. Latent: feature ที่วัดตรง ๆ ไม่ได้ (~0:43–1:05)

คำสุดท้ายบนสไลด์ศัพท์คือ Latent นิยามบนสไลด์ว่าเป็น feature ที่ "ซ่อน" อยู่ในข้อมูลซึ่งวัดโดยตรงไม่ได้ เป็นแก่นของข้อมูลแต่ไม่ใช่ feature ดั้งเดิมของชุดข้อมูล (บนสไลด์สะกด "orginal" ผิด) ~0:45–1:05 ผู้บรรยายอธิบายว่า latent แปลว่าซ่อน ในบริบทนี้หมายถึง feature ที่วัดตรง ๆ ไม่ได้ สิ่งที่เราวัดได้ หรือที่ถูกวัดมาแล้ว คือคำในชุดข้อมูล ส่วนสิ่งที่เราสนใจคือ latent feature ที่แทนบางอย่างที่เป็นแก่นของชุดข้อมูล

4. LSA เป็น NLP แบบ unsupervised และลดมิติ (~1:05–1:38)

ผู้บรรยายบอกว่า LSA เป็นทั้งเทคนิค NLP และเทคนิค unsupervised learning ซึ่งตรงข้ามกับ supervised learning: ใน supervised learning เรามี target หรือ label แต่ LSA ไม่มี เรามองสิ่งที่แฝงหรือมีอยู่ในตัวข้อมูลเอง ~1:05–1:20 จุดมุ่งหมายของ LSA คือสร้างตัวแทนของข้อความในรูปของ topic หรือ latent feature เหล่านี้ และ "ผลพลอยได้" คือเราจะลดจำนวนมิติของชุดข้อมูลข้อความตั้งต้นได้ ~1:20–1:36 ฉากนี้เป็นผู้บรรยายพูดหน้ากล้องและยืนที่โต๊ะ ไม่มีสไลด์

ผู้จัดทำเขียนการลดมิติเป็นรูปของขนาดเมทริกซ์ เพื่อให้เห็นว่า "ผลพลอยได้" หมายถึงอะไรเป็นตัวเลข

5. LSA สองขั้นตามแผนภาพ (~1:38–1:50)

2.ตัวอย่างของคลิปคือ X ขนาด 4 × 9; "the quick brown fox" = (1, 0, 1, 0, 1, 0, 0, 1, 0); ป้ายแถวที่ 3 บนตารางต้องอ่านเป็น "the quick red dog" (ผู้จัดทำตรวจ)
