บทสรุปย่อ

คลิปนี้เป็นวิดีโอเดโม 3 นาทีของ Transformer Explainer เว็บเครื่องมือที่รันโมเดล GPT-2 ที่ฝึกมาแล้วในเบราว์เซอร์ของผู้ใช้ เพื่อให้ผู้เริ่มต้นเห็นว่า Transformer เปลี่ยนข้อความที่ป้อนให้เป็น token ถัดไปอย่างไร คลิปไม่มีเสียงบรรยายที่ถอดได้ ข้อมูลทั้งหมดมาจากข้อความ caption บนจอและหน้าจอของเครื่องมือเอง ลำดับที่โชว์คือ ปรับ Temperature และ sampling ดูความน่าจะเป็นของคำถัดไป สร้าง token ใหม่ ดู attention matrix และ attention head แต่ละตัว ตาม matrix multiplication ทีละขั้น และดูส่วนประกอบเสริมอย่าง Dropout, Residual Connection, Layer Normalization

โหมดเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ ครบทุกประเด็น (license มาตรฐานของ YouTube) คลิปไม่มี caption track และไม่มีบทพูดที่อ่านได้ เนื้อหามาจากข้อความ caption บนจอและภาพหน้าจอ

1. ที่มาและภาพรวมของเครื่องมือ (~0:00–0:25)

คลิปเปิดด้วยข้อความว่า Transformer Explainer เป็นเครื่องมือ interactive visualization ที่ช่วยให้ผู้เริ่มต้นเรียนรู้ว่า LLM อย่าง GPT ทำงานอย่างไร (~0:06) จากนั้นสไลด์ระบุว่าเครื่องมือรันโมเดล GPT-2 ที่ฝึกมาแล้ว ในเบราว์เซอร์ของผู้ใช้เอง (~0:12) สไลด์วาดโครงสร้างตั้งแต่ Input Text เข้า Input Embedding แล้วผ่าน Transformer Block ซึ่งประกอบด้วย Masked Multi-Head Self-Attention ตามด้วย Add & Norm แล้ว MLP ตามด้วย Add & Norm อีกชั้น โดยบล็อกนี้ "Repeated N times" จากนั้นเข้า Linear & Softmax และออกเป็น Output Probabilities ซึ่งใช้เลือก Next Token (~0:12) caption ถัดมา (~0:22) สรุปเป้าหมายว่าเครื่องมือช่วยให้ผู้ใช้เรียนรู้ว่า Transformer เปลี่ยนข้อความอินพุตให้เป็น token ถัดไปอย่างไร และมี caption อีกบรรทัดว่า "Explore how Transformers work in your browser right now!" ชวนให้ลองดูการทำงานของ Transformer ในเบราว์เซอร์ของตัวเองได้ทันที หน้าจอเครื่องมือในช่วงนี้เป็นแผนภาพเดียวที่ไหลจากซ้ายไปขวา ซ้ายคือ Embedding กลางคือ Multi-head Self Attention กับ MLP ขวาคือรายการ Probabilities

2. ปรับ Temperature และดูความน่าจะเป็นของคำถัดไป (~0:25–0:55)

caption บอกให้ปรับ แถบเลื่อน Temperature เพื่อควบคุมความน่าจะเป็นของคำที่โมเดลทำนาย (~0:30) ในหน้าจอ ตัวอย่างข้อความคือ Data visualization empowers users to … และคอลัมน์ Probabilities ทางขวาเรียงคำที่เป็นไปได้ โดยที่ Temperature 0.8 และ Sampling แบบ Top-k (k=5) คำ visualize ได้ 54.67% รองลงมา create 20.87%, see 12.09%, make 6.26%, easily 6.11% และคำที่เหลือเป็น 0% (~0:30) จากนั้น caption แนะนำให้คลิก Probabilities เพื่อดูรายละเอียด (~0:45) การ์ดที่เปิดขึ้นชื่อ "Probability of "create" token being sampled" และเดินสูตรเป็นสามช่อง ได้แก่ Scaled logit, Top-k Filtering (k=5) และ Softmax ค่าที่เห็นคือ logit −136.68 หารด้วย temperature 0.8 ได้ −170.85, ถ้า logit อยู่ใน Top-5 จึงคงค่าไว้ ไม่เช่นนั้นเป็น −∞ จากนั้นขั้น Softmax นำ exp(−170.85) หารด้วยผลรวม exp ของ scaled logit ทุกคำที่ผ่าน Top-5 ได้ 20.87% ตารางด้านข้างมีคอลัมน์ Tokens, Logits, Scaled logits, Top-k, Softmax ให้เทียบทีละคำ (~0:45–0:52)

3. Sampling แบบ Top-p (~0:55–1:10)

ที่ราว 1:00 ตัวเลือก Sampling ถูกสลับเป็น Top-p (p=0.5) caption อธิบายว่า Top-p เลือกจาก "ชุดโทเค็นที่เล็กที่สุดซึ่งความน่าจะเป็นสะสมเกิน p" การ์ดของคำ visualize เดินสี่ช่อง คือ Scaled logit (−135.91 หาร 0.8 = −169.89), Softmax, Top-p Filtering (ถ้าความน่าจะเป็นสะสม ≤ 0.5 คงค่า 0.35 ไว้ ไม่เช่นนั้นเป็น 0) และ Normalization ที่นำ 0.35 หารด้วยผลรวมของค่าที่รอด (0.35 + 0.13 + 0.08) ได้ visualize = 62.39% ในตารางมีคอลัมน์ "Softmax & Top-p" ที่ไฮไลต์เฉพาะสามคำแรก (visualize 0.35, create 0.13, see 0.08 มีป้าย sum=0.56) ส่วนคำอื่นถูกขีดฆ่า และคอลัมน์ Normalization แสดง visualize 62.39%, create 23.81%, see 13.80% ที่เหลือ 0% สมการของ Top-p (แสดงบนจอ: ช่อง Top-p Filtering และ Normalization)

4. สร้าง token ถัดไปและป้อนข้อความเอง (~1:10–1:40)

caption บอกให้กด Generate เพื่อสร้าง token ถัดไปแล้วดู GPT-2 อัปเดตค่าภายในทั้งหมดของมันได้ในเบราว์เซอร์ของผู้ใช้เอง (~1:15) ระหว่างรอ ช่องอินพุตแสดงจุดสามจุดต่อท้ายข้อความ ในภาพ Temperature ถูกตั้งเป็น 2 และ Sampling เป็น Top-p ที่ p=0.3 ต่อมา caption บอกว่าผู้ใช้ สร้างอินพุตของตัวเองได้เลย (~1:30) หน้าจอสลับไปที่ตัวอย่างข้อความ IEEE VIS conference is … และมีเมนู Examples ให้เลือกตัวอย่างสำเร็จรูป

5. Attention matrix และ attention head (~1:40–2:30)

caption (~1:45) ให้คลิกที่ attention matrix เพื่อดูว่า token โต้ตอบกันอย่างไร ภาพแสดงเส้นสาย Query, Key, Value แยกสีและเขียนชื่อ token (Data, visualization, em, powers, users, to) ทุกเส้น เส้น Query และ Key ไหลไปรวมที่ matrix จุดสีม่วงขนาด 6 × 6 ที่มีป้าย Attention กับไอคอนแว่นขยาย ผลของ Value ไหลไปรวมเป็น Out ในภาพเดียวกัน หลังคลิก caption (~1:52) บอกให้เลื่อนเมาส์ไปที่แต่ละองค์ประกอบเพื่อดูสูตรและค่า attention score แต่ละค่า

สามขั้นที่เห็นเรียงต่อกันคือ Dot product, Scaling · Mask (ป้ายสูตรที่ขึ้นตอน hover คือ QKᵀ/√d_k + M) และ Softmax · Dropout แต่ละ matrix มีแถบสีกำกับช่วงค่า ตามที่อ่านได้จากภาพ Dot product อยู่ที่ −25.3 ถึง 7.4, Scaling · Mask เริ่มที่ −3.0 และ Softmax · Dropout อยู่ที่ −1.0 ถึง 1.0 ในขั้น Mask เซลล์ฝั่งขวาบนของ matrix เป็นสีเทา ส่วนหลัง Softmax แถวแรกเหลือจุดเข้มเพียงจุดเดียว ต่อมา (~2:00) caption บอกให้กดปุ่มลูกศรเพื่อดู attention head แต่ละหัว ภาพที่ตามมาแสดงป้าย "Head 2 of 12" และ "Head 4 of 12" ซึ่งแสดงทีละหัว โดยหัวอื่นซ้อนเป็นกองการ์ดอยู่ด้านหลัง สมการของสามขั้นใน attention

6. ตาม matrix multiplication ทีละขั้น (~2:25–2:55)

caption (~2:45) ให้คลิก เส้นทางสีไล่ระดับ (gradient path) เพื่อตาม matrix multiplication ทีละขั้นและดูว่าโมเดลใช้น้ำหนักเปลี่ยน embedding อย่างไร หน้าต่างที่เปิดชื่อ MLP Compression วางสมการเป็นรูปเมทริกซ์: Expanded Embeddings ขนาด (6, 3072) คูณ Compression Weights ขนาด (3072, 768) บวก Compression Bias (768) ได้ Compressed Embeddings ขนาด (6, 768) ทุกช่องกำกับขนาดไว้ ก่อนหน้านั้นที่ ~2:15 และ ~2:30 หน้าจอหลักแสดง Head 4 of 12 โดยไม่มี caption ใหม่

b_compCompression Bias(768)แสดงบนจอ
X_compCompressed Embeddings(6, 768)แสดงบนจอ

หน้าต่างนี้แสดงรูปแบบ × และ + ของเมทริกซ์ สัญลักษณ์ในสมการ (10) เป็นชื่อย่อของผู้จัดทำ

7. ฟีเจอร์เสริมของสถาปัตยกรรม และท้ายคลิป (~3:00–3:24)

caption (~3:00) บอกให้ตรวจดูฟีเจอร์สถาปัตยกรรมขั้นสูง ได้แก่ Dropout, Residual Connections และ Layer Normalization ในภาพ ป๊อปอัปของ Dropout อธิบายว่าเป็นการปิด neuron ที่ถูกสุ่มเลือก และใช้เฉพาะตอนฝึก (training) มีปุ่ม "Read more" ต่อท้าย หน้าจอตอนนี้ขึ้นว่า Transformer Block 6 และมีปุ่มลูกศร < > ข้างชื่อบล็อก (ผู้จัดทำเข้าใจว่าใช้สลับดูบล็อกอื่น) คลิปจบด้วยการ์ดชื่อ Transformer Explainer พร้อมคำบรรยายใต้ชื่อว่าเป็นการเรียนรู้ LLM Transformer ผ่านคำอธิบายภาพแบบโต้ตอบและการทดลอง (~3:18) และลิงก์ demo กับ code บน GitHub

Key Takeaways

1.เครื่องมือรัน GPT-2 ที่ฝึกแล้วในเบราว์เซอร์ผู้ใช้ และผู้ใช้ป้อนข้อความของตัวเองได้
2.Temperature และ Sampling (Top-k, Top-p) เปลี่ยนความน่าจะเป็นของคำถัดไป และการ์ดสูตรเดินตั้งแต่ logit จนถึงเปอร์เซ็นต์ที่เห็น
3.Attention เห็นเป็น matrix ที่แยกขั้น Dot product, Scaling · Mask, Softmax · Dropout และ hover ดูสูตรกับค่าได้ทีละเซลล์ ดูทีละ head (Head x of 12)
4.คลิกเส้นสายใน MLP เพื่อดู matrix multiplication พร้อมขนาดของทุกเมทริกซ์
5.Dropout, Residual Connections และ Layer Normalization ตรวจดูได้ ป๊อปอัปมีปุ่ม Read more
